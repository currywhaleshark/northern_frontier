# 염부 스프라이트 QA

## 공통

- 방향은 오른쪽 측면 한 방향을 원본으로 쓰고 왼쪽은 런타임에서 반전한다.
- 대기·걷기·바닷물 취수·가마 작업 각 4프레임을 사용한다.
- 대기는 승인된 기준 인물과 가이드, 나머지는 추출한 대기 0번 프레임과 상태 가이드만 참조했다.
- 보행의 발 교차, 취수의 허리 굽힘과 바가지 이동, 가마 작업 도구의 왕복이 읽힌다.
- 자동 검사에서 모든 행은 오류 없이 통과했다. 남성 대기는 의도적으로 움직임이 작아 motion 경고가
  있었지만 정지 연출로 승인했다.

## 남성

- 옅은 갈색 저고리, 짙은 바지, 검은 머릿수건과 작은 상투를 유지한다.
- 최초 가마 작업 행은 4번 칸 아래 고립된 검은 점 때문에 폐기하고 재생성했다. 승인 행에는 고립
  픽셀이 없다.

## 여성

- 옅은 갈색 저고리와 짙은 치마형 작업복을 유지한다.
- 정수리 상투를 금지하고 목덜미에 낮게 붙인 쪽머리를 대기·걷기·취수·가마 작업 전 행에서 유지한다.
- 도구가 신체에서 분리되거나 쪽머리가 높은 상투로 변하는 프레임이 없다.
