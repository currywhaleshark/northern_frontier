# 머리 영역 검출 — 비전 모델(제미나이) 지시 프롬프트

전술 스프라이트의 표시 크기를 머리 크기 기준으로 정규화하기 위해, 시트별 셀마다
머리 바운딩 박스를 비전 모델로 검출한다. 아래 프롬프트를 **시트 1장당 1회** 사용한다
(이미지 1장 + 프롬프트 1개씩, 새 대화 권장).

결과 JSON은 이 폴더에 아래 이름으로 저장한다. 파일이 있으면
`npm run gen:sprite-metrics`가 휴리스틱 대신 이 좌표를 사용한다.

| 시트 이미지 (public/assets/tactical/) | 저장 파일명 | 격자 |
|---|---|---|
| defender-roles-poses-v2.png | defenderRoles.json | 8칸 × 4줄, 셀 84×120px (전체 672×480) |
| defender-weapons-poses-v2.png | defenderWeapons.json | 6칸 × 4줄, 셀 84×120px (전체 504×480) |
| defender-default-weapons-poses-v1.png | defenderDefaultWeapons.json | 6칸 × 4줄, 셀 84×120px (전체 504×480) |
| faction-raiders-poses-v2.png | raiders.json | 6칸 × 4줄, 셀 168×120px (전체 1008×480) |
| court-army-poses-v2.png | court.json | 5칸 × 4줄, 셀 168×120px (전체 840×480) |

주의: 아군 3개 시트(defender*)는 공통 기준으로 정규화되므로 **셋 다 제공하는 것이
가장 좋다.** 적 시트(raiders/court)는 각자 자기 시트 기준이라 개별 제공해도 된다.

## 프롬프트 템플릿 (아래 { } 부분만 시트에 맞게 교체)

```
이 이미지는 게임 스프라이트 시트이고, 가로 {COLUMNS}칸 × 세로 4줄 격자다.
각 칸의 크기는 {CELL_W}×120픽셀, 이미지 전체 크기는 {IMG_W}×480픽셀이다.
줄은 위에서부터 r0(대기), r1(공격), r2(피격), r3(부상·무릎 꿇음) 자세다.
칸은 왼쪽부터 c0, c1, … 순서다.

모든 칸(총 {TOTAL}개)에 대해 캐릭터 "머리 영역"의 바운딩 박스를 찾아라.

머리 영역의 정의:
- 머리에 쓴 것(투구, 갓, 전립, 두건, 상투, 벙거지 등)의 최상단부터 턱 끝까지
- 갓·전립처럼 챙이 좌우로 넓은 모자는 챙 폭 전체를 포함
- 무기(창, 조총, 활, 칼, 농기구), 깃발, 화살통, 치켜든 팔·주먹은 제외
- 기마 유닛은 말 머리가 아니라 "타고 있는 사람"의 머리만
- 대포가 있는 칸은 대포가 아니라 옆에 있는 포병(사람)의 머리만
- 투구 꼭대기의 가늘고 긴 깃털·술 장식은 제외
- 고개를 숙이거나 엎드린 자세여도 그 자세 그대로의 머리 영역을 잡을 것

출력 형식: 설명 없이 JSON 배열만 출력하라.
[
  {"label": "r0c0", "box_2d": [ymin, xmin, ymax, xmax]},
  ...
]
- box_2d는 이미지 "전체" 기준 0~1000으로 정규화된 [ymin, xmin, ymax, xmax]
- label은 r{줄}c{칸}, 왼쪽 위 칸이 r0c0
- 모든 칸을 빠짐없이 포함하고, 캐릭터가 없는 빈 칸은 "box_2d": null로 표기
```

## 결과 반영 절차

1. 제미나이 출력(JSON 배열)을 그대로 이 폴더의 해당 파일명으로 저장
2. `npm run gen:sprite-metrics -- --debug <임시폴더>` 실행
3. 임시폴더의 `<시트키>-debug.png`에서 파란 박스(비전 좌표)가 머리에 맞는지 눈으로 확인
4. 이상 없으면 커밋 (src/render/tacticalSpriteMetrics.ts가 갱신됨)

검증 팁: 라벨과 박스 위치가 어긋나면 스크립트가 경고를 출력하고 박스 위치를
우선한다. 누락된 칸은 휴리스틱으로 대체되고 경고가 뜬다.
