# P9 사후 전술 UI 스크린샷 기준선 (2026-07-20, `eb92455` 기준)

P0 기준선(`../tactical-baseline-2026-07-20/`)과 같은 playwright 흐름을 P3 이후 배치
개편에 맞게 갱신해(`capture_p9.mjs` — 빈 카드 독 → 자동배치 → 배치 완료) 재촬영한 세트다.
1280×720·1920×1080 두 해상도, 방어전 준비/배치(빈 독·자동배치)/지휘/팝오버/재생/보고 + 사냥 배치.

P0 대비 비교 결론:

- 준비 화면·적 정보·미니맵·지휘 독 구조는 P0과 동일하다 (차이는 랜덤 날씨·준비점수·적 편제뿐).
- 배치 화면은 P3 의도대로 빈 무대 + 카드 독으로 바뀌었다. `defense-deployment-empty-*`가 새 시작
  상태이고, `defense-deployment-*`는 자동배치 직후다 (P0의 같은 이름 파일과 비교 대상).
- 사냥 배치도 공통 카드 독·분견대 편성을 쓴다 (P3 공통 분할·합류 계약의 의도된 변화).
- 의도되지 않은 회귀는 발견하지 못했다.

재촬영 방법: playwright는 레포 밖에 설치하고(`npm i playwright`), dev 서버(5173)를 띄운 뒤
`node capture_p9.mjs <outDir>` — 스크립트를 playwright가 설치된 디렉터리로 복사해 실행한다.
