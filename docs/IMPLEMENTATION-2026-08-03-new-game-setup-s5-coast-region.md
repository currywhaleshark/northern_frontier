# 새 게임 설정 S5 해안 지역 구현계획

> **계획 상태:** 미착수
> **상태 갱신:** 2026-08-03 — 해수 의미 계약, 남쪽 연속 해안, 자염막 생산 체인과 검증 범위를 확정했다.

- 작성일: 2026-08-03
- 상위 설계: [새 게임 설정 개편 설계](DESIGN-2026-08-01-new-game-setup.md)

## 1. 목표

해안을 네 번째 실제 지역 선택지로 연다. 지도 남쪽에 큰 연속 바다와 굽은 해안선을 만들고,
바닷물을 육상 통행과 건설을 막는 수역으로 취급하되 식수·농수·소방수로는 절대 쓰지 않는다.
바다는 계절과 날씨에 관계없이 결빙하지 않는다.

해안에서만 건설할 수 있는 `자염막`과 전용 직업 `염부`를 추가한다. 염부는 바닷물을 끌어다
장작으로 끓여 소금을 생산한다. 해안은 소금 자급과 교역 기회를 얻는 대신, 바다가 차지한
면적과 짧아진 담수 하천·희소한 수맥 때문에 농업용 물이 부족한 지역이 된다.

## 2. 확정 규칙

### 2.1 물의 의미 계약

지형 판정을 다음 세 의미로 분리한다.

| 판정 | 포함 지형 | 쓰임 |
|---|---|---|
| 담수 자연수 | `river`, `lake` | 주민 식수, 자연 급수권, 논, 흐르는 농수로 취수, 소방수 |
| 열린 수면 | `river`, `lake`, `sea` | 육상 이동·일반 건물 배치 차단, 수면 렌더·지형 마스크 |
| 해수 | `sea` | 자염막 입지·생산만 허용 |

- 기존 `isNaturalWaterTerrain`은 **담수 자연수** 의미를 유지한다. `sea`를 여기에 넣지 않는다.
- 열린 수면 판정을 새로 두어 지도 연결성, 장애물, 렌더 가림처럼 물의 물리적 면적만 필요한
  곳에서 쓴다.
- `sea`는 주민·습격자·전투 경로에 항상 통행 불가다. 강의 한겨울 통행이나 호수의 점진
  결빙 판정을 재사용하지 않는다.
- `sea`는 우물 산출, 자연 급수 반경, 논 배치, 농수로 취수, 가뭄 완화, 화재 물동이 수원에
  기여하지 않는다.
- `sea`에는 봄 대홍수·보 저수지·제방·다리·물레방아·강변 건물 규칙을 적용하지 않는다.

### 2.2 해안 지도 프로필

- 같은 시드와 옵션은 같은 지도를 만든다. 평원·산지·호수 RNG 결과는 바꾸지 않는다.
- 해안에서만 남쪽 경계 전체와 이어진 하나의 바다를 판다. 해안선은 완만한 큰 굽이와 작은
  만을 가지며 전체 지도 면적의 약 **18~24%**를 차지한다.
- 현행 남북 강은 바다에 닿는 하류가 `sea`로 합쳐진다. 남은 상류는 담수 `river`로 유지해
  시작 생활용 물은 남기되 평원보다 강의 유효 길이와 비옥지가 줄어든다.
- 바다는 비옥지 생성원이 아니다. 바닷가 땅은 해수에 가깝다는 이유만으로 `fertile`이 되지
  않는다.
- 일반 수맥은 평원 대비 개수 **0.65**, 반경 **0.85**, 용량·산출 **0.8**을 첫 기준값으로
  사용한다. 다만 모든 지도 크기에서 시작 정착지 수맥 하나는 현행 용량으로 보장한다.
- 숲·광물·서식지의 육지 밀도는 평원 기준을 유지한다. 바다가 차지한 면적만큼 지도 전체
  총량은 자연스럽게 줄지만 시작 숲·노두·서식지 보장은 깨지지 않는다.
- 마을 중심지와 시작 보장 지물은 열린 수면 위에 덮어쓰지 않으며 육상으로 서로 도달할 수
  있어야 한다.

### 2.3 바다 표현과 계절

- `sea` 전용 수면색과 반복 파문을 사용한다. 파문은 강처럼 한 방향으로 흘러내리지 않고
  해안선을 향해 밀려와 얕아지고, 육지 경계에는 옅은 포말을 둔다.
- 비·눈·계절색은 적용할 수 있지만 `frozenRiver`나 호수 얼음 단계는 절대 적용하지 않는다.
- 겨울·혹한·폭설에도 모든 바다 타일은 액체 수면으로 남고 육상 통행 불가를 유지한다.
- 산·광상·건물 돌출 스프라이트는 기존 수면 가림 마스크를 열린 수면까지 확장해 바다를
  침범하지 않게 한다.

### 2.4 자염막과 염부

- 건물 ID는 `saltworks`, 표시명은 **자염막**, 직업 ID는 `saltMaker`, 표시명은 **염부**로 한다.
- 해안 지역의 개척지 등급부터 건설 메뉴에 열린다. 다른 지역에서는 건설할 수 없고, 메뉴에는
  지역 전용 사유를 명확히 표시한다.
- 크기는 2×2 육지 건물, 작업자 2명, 비고유 건물이다. 네 변 바깥의 직교 인접 타일 중 하나
  이상이 `sea`여야 한다. 강·호수와의 인접은 입지 조건을 만족시키지 않는다.
- 첫 기준 건설비는 목재 10·돌 4·도구 1, 공사량 6 건축가-일이다.
- 염부는 바닷물 운반을 별도 자원으로 저장하지 않는다. 완공된 자염막의 해수 인접 조건을
  매 작업 때 확인하고 장작만 작업장으로 공급한다.
- 염부 1명의 기준 생산은 하루 소금 **0.75**, 소금 1당 장작 **1.25**다. 두 슬롯을 모두 쓰면
  하루 장작 1.875를 태워 소금 1.5를 만든다. 이는 자반·김장용 자급에는 충분하지만 무인
  무제한 교역 수익이 되지 않는 첫 밸런스다.
- 바다는 결빙하지 않으므로 계절 생산 잠금은 없다. 겨울 생산은 주거 난방과 같은 장작을
  소비한다는 비용으로 억제한다. 자염막 생산은 우물·담수 공급률의 영향을 받지 않는다.
- 생산물은 건물 재고에 쌓이고 운반꾼이 기존 물류 규칙으로 창고에 옮긴다. 입력 부족·입지
  상실 시 작업 문구로 이유를 알린다.
- 건물 관리창에 작업자 배정, 장작 입력, 소금 출력과 기준 환산량을 표시한다. 해안 첫 선택과
  자염막 첫 건설에는 해수 비음용·비관개 및 겨울 장작 경쟁을 설명한다.

## 3. 구현 단계

### P0. 의미 계약과 회귀 안전망

- [ ] `Terrain`에 `sea`, 상수·저장 검증·디버그 지형 표기에 바다를 추가한다.
- [ ] 담수 자연수/열린 수면/해수 헬퍼를 정의하고 기존 물 판정 사용처를 분류한다.
- [ ] 바다가 식수·농수·소방수에 포함되지 않고 항상 통행 불가인 표적 테스트를 먼저 둔다.

### P1. 결정적 해안 생성과 자원 프로필

- [ ] 해안에서만 남쪽 연속 바다와 굽은 해안선을 생성한다.
- [ ] 강 하구 연결, 중심지 육상 안전 반경, 시작 숲·노두·수맥·서식지 보장을 유지한다.
- [ ] 해안 수맥 배율과 담수 비옥지 생성 규칙을 연결한다.
- [ ] 소·중·대 지도와 여러 시드에서 바다 비율·연결성·결정론·육상 도달성을 측정한다.

### P2. 해수 시스템 경계

- [ ] 주민·습격자·외부 거점 경로, 건물 배치, 농수로, 논, 급수, 소방, 홍수의 해수 경계를
  고정한다.
- [ ] 강 하구에서 `river`와 `sea`가 맞닿아도 해수를 따라 농수로가 흐르거나 급수권이
  퍼지지 않음을 검증한다.
- [ ] 연중 날짜·날씨 표본에서 바다가 얼거나 건너갈 수 없음을 검증한다.

### P3. 자염 생산 체인

- [ ] `saltworks`·`saltMaker` 타입, 명칭, 건설 메뉴, 작업자 배정과 저장 호환을 추가한다.
- [ ] 해안 지역 잠금과 2×2 해수 인접 배치를 실제 건물 footprint 기준으로 구현한다.
- [ ] 장작 공급 → 소금 생산 → 건물 재고 → 운반꾼 회수 흐름과 중지 사유를 연결한다.
- [ ] 생산률·연료비·도구 마모·숙련·사기/등급 생산 보정을 기존 생산직 규칙과 맞춘다.
- [ ] 자염막 도움말과 관리창 수치를 추가한다.

### P4. 렌더와 스프라이트 스튜디오

- [ ] 바다 수면·해안 포말을 강·호수와 구분해 그리고 결빙 렌더 경로에서 제외한다.
- [ ] 산·광상·외부 거점의 수면 가림 마스크를 `sea`까지 확장한다.
- [ ] 자염막의 계절별 표준/HD 표시와 염부 작업 위치를 게임에서 확인한다.
- [ ] 스프라이트 스튜디오 건물/직업 레지스트리에 신규 타입을 반영하고 생성 파일 검사를
  통과한다.

### P5. 통합·문서·완료 판정

- [ ] 구 저장은 바다·자염 타입이 없어도 그대로 로드되고 기존 지역 생성 결과가 유지된다.
- [ ] 튜토리얼 고정 평원과 기존 평원·산지·호수 회귀를 통과한다.
- [ ] 표적 테스트, 전체 core 테스트, 타입 검사, 프로덕션 빌드를 통과한다.
- [ ] 실제 시작 설정에서 해안을 골라 바다·하구·자염 배치·생산·한겨울 비결빙을 확인한다.
- [ ] 본 문서, 상위 설계와 `PLAN-STATUS.md`를 구현 근거와 함께 완료로 갱신한다.

## 4. 표적 검증 행렬

| 범주 | 반드시 확인할 것 |
|---|---|
| 생성 | 3크기×다중 시드에서 남쪽 경계 연결 바다 1개, 18~24%, 같은 옵션 결정론 |
| 시작 보장 | 중심지 육상 footprint, 시작 수맥·숲·노두·서식지, 상호 육상 도달 |
| 담수 | 바다 식수 0, 자연 급수권 0, 논·농수로 취수 불가, 우물 배율과 시작 우물 보장 |
| 계절 | 1년 전 날짜 표본에서 바다 비결빙·항상 육상 통행 불가, 강·호수 기존 결빙 유지 |
| 재해 | 바다 홍수·보·제방·물레방아·소방 수원 제외, 담수 강 기존 동작 유지 |
| 자염 | 해안 전용 해금, 2×2 해수 인접, 장작 1.25→소금 1, 2인 병렬 생산·물류·중지 사유 |
| 저장 | 신규 지형·건물·직업 왕복, 구 저장 기본값, 다른 지역 저장 무변형 |
| 화면 | 시작 설정 카드, 미니맵, 바다/해안선, 겨울 수면, 자염막/염부/관리창, 스튜디오 |

## 5. 비범위와 후속

- 어선, 포구 작업영역, 선체 상태, 바다 항행과 해상 어장은 어선 설계 F4에서 구현한다.
- 염전·천일염, 기수 지형, 조수·해일, 항구 교역 보너스는 이번 S5에 넣지 않는다.
- 해수 담수화나 바닷물 소방은 제공하지 않는다.
- 첫 밸런스 수치는 표적 테스트와 실제 한 해 플레이에서 조정할 수 있으나, **해수 비음용·
  비관개·비결빙**과 **해안 전용 자염** 규칙은 바꾸지 않는다.
