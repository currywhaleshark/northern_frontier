# 재해 확장 D2 — 늦서리 구현계획

> **계획 상태:** 완료
> **상태 갱신:** 2026-07-29 — 늦서리 발생·여름 재파종·3일 실제 날씨 판정·공유 경보/백화와 표적 회귀, 프로덕션 빌드를 완료했다.

- 기준 설계: [재해 확장 설계](DESIGN-2026-07-28-disasters.md) §3-2
- 선행: D0 지연 재해 대기열, D1 이른 서리의 백화 오버레이
- 권장 모델: `gpt-5.6-terra` / 추론 수준 `high`

## 확정 계약

- 봄의 실제 `frost`·`coldSnap` 날에, 올해 봄에 파종해 자라는 논밭만 후보가 된다.
- `갈아엎고 다시 심는다`는 즉시 확정 선택이다. 밭은 메밀, 논은 벼로 전환하고
  `fieldGrowth`·`sownArea`를 초기화해 여름 파종부터 다시 시작한다.
- `기다린다`는 이후 3일의 실제 날씨를 센다. 찬 날이 2일 이상이면 고사하고, 미만이면
  기존 성장도를 유지한다. 기다리기에는 시뮬레이션 RNG를 쓰지 않는다.
- 측우기 수치는 기후 기반 근사 예보다. 실제 결과는 날씨표만으로 정한다.
