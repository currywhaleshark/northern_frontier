# 후반 엔딩 — 북방 통일 전쟁과 연대기의 갈래 (설계)

> **계획 상태:** 일부 완료
> **상태 갱신:** 2026-08-07 — H0 1차 구현으로 화면 내 주민 말풍선, 결정적 일일 슬롯,
> 상태·계절·잡담·위협 공급자, 빈도 설정과 v67 반복 방지 장부를 연결했다. 습격은 외교
> 귀띔/시설 경보와 실제 근접 발견을 분리하고 경보/기습 말투·색·유지 시간을 달리했다.
> 부족 전쟁·북병사 교체 사전 소문과 실제 식단 편중 불평도 연결했으며, 역사 전환의
> 사전 소문은 H1 역사 시계 구현과 함께 붙이는 후속 H0 범위다.

- 작성: 2026-07-29
- 전제: 부(府) 승격 이후의 장기 플레이에 서사적 목적지를 만든다.
  기존 부 승격 엔딩("맞거나 계속")은 그대로 두고, 그 뒤의 이야기다.
- 선행 계획: [외교 인물](DESIGN-2026-07-30-diplomatic-figures.md) —
  부족 지도자 5인·북병사가 이미 게임에 있다.
  [외교 활동](DESIGN-2026-07-30-diplomatic-actions.md) — 예물·맹약·귀띔·
  근접 경고·협정·원병까지 구현됐다. 역사 시계는 이 두 층 위에서 돈다.

## 0. 원칙 (전 항목에 우선)

1. **조건은 비공개, 판정은 결정적.** 엔딩 조건을 UI에 나열하지 않는다.
   그러나 조건을 아는 플레이어는 반드시 원하는 엔딩에 도달할 수 있어야 한다 —
   난수가 엔딩을 막는 설계(확률 게이트, 월드 생성 복권)는 금지.
2. **계속 플레이가 기본값.** 조건을 충족해도 커밋은 항상 선택이다. 거절하거나
   무시하면 정치 노선에 들어가지 않은 채 계속 플레이한다. 세계의 역사 변화는
   진행되지만, 커밋하지 않은 플레이어에게 배드엔딩을 강제하지 않는다.
3. **배드엔딩 = 커밋한 노선의 실패**이며 게임오버다(기존 중심지 함락과 동일 처리).
   실패 판정도 난수가 아니라 준비도와 전투 결과로 결정된다.
4. **굿엔딩 후에는 계속 플레이할 수 있다.** 엔딩 연출을 본 뒤 샌드박스로 복귀하고,
   이후 관청 메뉴의 "연대기 마감"으로 **원하는 때에 언제든** 공식 종료(엔딩 재연출 +
   기록 화면)를 할 수 있다.
5. **역사 시계는 보이게, 조건은 숨기게.** 정세의 진행(누가 강해지는가, 전쟁이
   어디까지 왔는가)은 소문·사절·시세로 계속 노출한다. 조건을 아는 플레이어가
   "언제까지 무엇을 준비해야 하는지"를 게임 안에서 읽을 수 있어야 한다.
6. **비강제는 무영향이 아니다.** 플레이어가 개입하지 않아도 영역·깃발·활동대·
   난민·시세와 연대기는 바뀐다. 다만 무시했다는 이유만으로 관계가 깎이거나,
   콘텐츠가 잠기거나, 결말용 대공성·게임오버가 발동해서는 안 된다.
7. **약속의 의미는 공개한다.** 수치 문턱은 숨기되, 커밋하면 앞으로 병력·공물·
   방어를 요구받을 수 있다는 사실과 실패 위험은 수락 전에 명시한다.
8. **세계의 변화는 기존 플레이로 체감한다.** 별도 심부름 목록을 늘리지 않고
   외교·교역·습격·난민·방문객·타 거주지 활동·연대기 체계를 재사용한다.

## 0-1. 선행 기반 H0 — 주민 말풍선 소문망

로그에만 쌓이는 평시 정보는 플레이 중 놓치기 쉽다. 살아 있는 마을 주민 한 명이
화면에서 직접 잡담하듯 말풍선을 띄워 **마을의 상태와 바깥 정세를 생활 속에서
발견하게 하는 공통 전달망**을 먼저 만든다. 역사 시계는 이 전달망의 `주변 정세`
공급자가 된다.

말풍선은 새로운 선택창이나 퀘스트가 아니다. 주민이 알고 있는 사실을 보여 주는
비차단 연출이며, 관계·만족도·자원에 직접 효과를 주지 않는다. 중요한 외교·전쟁
소문은 기존 로그에도 한 줄 남겨 기록성을 보존한다.

### 0-1-1. 표시 빈도와 화자

- 기본 빈도는 **게임 날짜 하루 2회**다. 오전 생활이 시작된 뒤 한 번, 오후에 한 번을
  기본 슬롯으로 두되 정확한 시각은 `월드 시드 + 날짜 + 슬롯`으로 결정해 무작위처럼
  보이면서 저장·테스트에서는 재현 가능하게 한다.
- 현재 화면 안에 있는 생존·의식 있음·비전투·비수면 주민 중 대사에 맞는 화자를
  고른다. 배를 타고 이동 중이거나 전술 전투 중인 주민은 제외한다. 직업 대사는 해당
  직업자를 우선하고, 일반 소문은 성인 주민 누구나 말할 수 있다.
- 적합한 주민이 화면에 없으면 카메라를 옮기거나 화면 밖에 말풍선을 띄우지 않고
  해당 슬롯을 잠시 미룬다. 하루가 끝날 때까지 화자를 찾지 못하면 조용히 소멸한다.
- 동시에 보이는 말풍선은 1개, 표시는 실제 시간 4~6초다. 주민 머리 위를 따라가되
  화면 가장자리와 상단 HUD 안쪽으로 고정하며 카메라 이동·배속을 방해하지 않는다.
- 일시정지 중에는 새 말풍선을 만들지 않는다. 고배속에서는 최소 실제 시간 간격을
  두어 여러 날의 대사가 한꺼번에 쏟아지지 않게 하고, 지나간 일반 잡담은 재생하지
  않는다.
- 설정의 `주민 말풍선` 빈도는 `끄기 / 적게(하루 1회) / 보통(하루 2회) / 자주(하루
  3~4회)`를 제공한다. 끄더라도 중요한 소문의 로그 기록은 유지한다.

### 0-1-2. 대사 공급자와 우선순위

| 공급자 | 실제 조건 | 역할 | 예시 |
|---|---|---|---|
| **예고 소문** | 예정된 부족 전쟁·참전 요청·북병사 교체·역사 전환에 사전 창이 열림 | 앞으로 벌어질 일을 단정하지 않고 정황으로 예고 | “골간과 올량합 사이가 요즘 심상치 않다더라.” · “새 북병사는 송사에 엄한 사람이라던데.” |
| **습격 조짐** | 위협 상승 또는 미발견 습격대의 접근 흔적을 주민·순찰자가 실제 포착 | 정식 경보 전의 불안과 대비 계기. 세력·규모·정확한 위치는 감춤 | “개들이 자꾸 북쪽만 보고 짖는군.” · “서쪽 산길에 낯선 말발굽 자국이 많다더라.” |
| **주변 정세** | 타 거주지 활동·사냥감 감소·연기·피난민·시장 변화가 실제 발생 | 화면 밖 세계가 움직인다는 감각 | “니마차 사냥꾼들이 담비가 씨가 말랐다며 투덜대더군.” · “북쪽 하늘에 저 연기는 뭐지?” |
| **마을 상태** | 식단 편중·시신 방치·물/땔감 부족·과밀·질병·외곽 피해 등 실제 상태 문턱 충족 | 관리창을 열지 않아도 민생 문제를 발견 | “고기만 먹으니 이제 풀 냄새라도 반갑겠어.” · “저 시신은 언제까지 저렇게 둘 셈이지?” |
| **일과·계절 잡담** | 직업·날씨·계절·시간대와 일치 | 정보가 없는 날의 생활감 | “서리가 내리기 전에 장작을 더 들여놔야겠군.” |
| **순수 잡담** | 경고·소문 후보가 부족함 | 반복되는 경고 피로를 줄이는 완충 | 인사·가족·날씨·일거리 이야기 |

선정 우선순위는 `아직 전달하지 않은 예고 소문 → 새로운 마을 상태 → 주변 정세 →
일과·계절 잡담 → 순수 잡담`이다. 다만 하루 두 슬롯을 모두 불평으로 채우지 않도록
마을 상태 대사는 하루 최대 1회로 제한한다.

### 0-1-3. 정확성·반복·예고 규칙

- 모든 정보성 문구는 자유 생성하지 않고 `조건 판정 + 문구 묶음 + 허용 화자`로
  등록한다. 조건이 해소되면 해당 대사는 즉시 후보에서 빠진다.
- 같은 문구는 최소 7일, 같은 사실은 최소 3일 동안 반복하지 않는다. 미해결 문제가
  계속되어 다시 말할 때에는 두 번째 문구를 사용해 기계적 반복을 줄인다.
- 먼 정세는 “그러더라”, “심상치 않다”, “연기가 보인다”처럼 주민이 알 수 있는
  범위로 말한다. 숨은 엔딩 수치, 확정되지 않은 공격 시점과 병력 규모는 발설하지
  않는다.
- 부족 전쟁 참전 요청은 3~10일 전, 북병사 교체는 부임 당일 또는 직전, 역사 시계의
  연간 전환은 §1-1의 징후 기간에 소문 후보를 등록한다. 소문을 못 들었어도 사건은
  정상 진행하고, 선택 기한이나 결과가 달라지지 않는다.
- 순수 잡담과 상태 대사는 로그를 오염시키지 않는다. 역사·외교 예고처럼 나중에
  찾아볼 가치가 있는 정보만 기존 로그와 함께 기록한다.

### 0-1-4. 습격 조짐과 파수꾼의 외침

[방어 개편](DESIGN-2026-08-01-defense-overhaul.md)의 기존 `warned`(조기 경보)와
`spotted`(지도상 발견)를 말풍선에 연결한다. **조짐, 발견, 정식 경보**를 섞지 않는다.

1. **막연한 불안** — 위협도가 높은 날에는 개 짖음, 낯선 사람, 산길 분위기 같은
   잡담이 후보가 될 수 있다. 실제 습격이 그날 반드시 발생한다는 뜻은 아니다.
2. **구체적인 흔적** — `state.raiders`가 생성됐지만 아직 `spotted`가 아닌 동안,
   순찰 파수꾼·사냥꾼·외곽 작업자가 실제 접근 방향의 발자국·부러진 덫·새 떼·먼지·
   말발굽 소리를 발견할 수 있다. 이 말풍선은 방향까지만 암시하고 세력과 전력은
   노출하지 않는다.
3. **조기 경보 전달** — `warned: true` 습격대가 생성되면 경보 출처에 맞는 화자가
   알린다. 망루·봉수·순찰이 출처일 때만 파수꾼이 외치고, 외교 귀띔은 사절이나
   전달자의 소문으로 표시한다.
4. **실제 근접 발견 외침** — 습격대가 기존 `spotDistance` 안으로 처음 들어온 순간에
   실제 경계 화자를 고르고 긴급 말풍선을 한 번 띄운다. 외교 귀띔 때문에 이미 지도에
   `spotted`로 표시된 무리도 근접 발견 외침은 별도로 한 번 발생할 수 있다. 예:
   “습격이다! 북쪽 숲길로 무장대가 온다!” · “봉수 올려라! 서쪽 고개에 기마대다!”

구체적인 흔적은 정식 경보가 아니다. `RaiderBand.warned`를 켜거나 미니맵에 적을
표시하거나 경보 방어 보너스를 주지 않는다. 모든 습격에 흔적을 보장하지도 않는다.
외곽에서 일하는 주민과 순찰자가 많을수록 후보가 늘지만, 봉수대·망루·외교 귀띔의
정식 조기 경보 가치는 그대로 남는다.

정식 발견의 화자 우선순위는 다음과 같다.

1. 경보에 기여한 망루 주둔 파수꾼
2. 순찰 중인 파수꾼
3. 가까운 수비병 또는 사냥꾼(파수꾼이 없을 때의 경계병 역할)

긴급 외침은 하루 2회 잡담 슬롯을 소비하지 않고 현재 잡담보다 우선한다. 붉은 테두리와
조금 큰 글씨로 4~6초 표시하며, 주민이 현재 화면에 있으면 머리 위에 붙인다. 실제
화자가 화면 밖이면 지도 화면 위쪽에 `파수꾼 ○○의 외침`과 접근 방향을 표시해
카메라를 강제로 옮기지 않는다. 말풍선 설정을 꺼도 기존 경보 로그·알림·미니맵·모달은
그대로 작동한다.

근접 발견 외침은 `warned` 여부에 따라 같은 문구를 쓰지 않는다.

| 발견 상태 | 화자의 상황 | 대사 원칙 | 예시 | 표시 |
|---|---|---|---|---|
| **경보된 습격** (`warned: true`) | 이미 소문·외교 귀띔·봉수·망루 경보를 받고 기다리던 무리를 확인 | 침착한 확인과 배치 명령. 알려진 방향·세력 정보를 활용할 수 있음 | “예고한 무리가 보인다! 북문 쪽이다, 각자 자리로!” · “봉수에서 알린 기마대다! 활을 준비해라!” | 황적색 경계선, 5~6초 |
| **기습 발견** (`warned: false`) | 경보 없이 가까이 온 무리를 뒤늦게 발견 | 짧고 다급한 비명과 즉시 경보. 세력 설명보다 위험·방향을 먼저 말함 | “기습이다! 무장대가 코앞이다!” · “적이다! 종을 울려라, 서쪽이다!” | 진한 적색 경계선, 3~4초 |

경보된 습격 대사는 “이제 왔다”는 뉘앙스로 준비된 방어 보너스와 느린 접근을
체감시킨다. 기습 대사는 읽는 시간이 전투 준비를 방해하지 않도록 한 문장으로 제한하며,
상세 세력·규모는 기존 알림과 습격 대응창에서 확인하게 한다. 외교 귀띔으로 경보된
경우에는 “귀띔받은 무리”, 봉수·망루 경보는 “봉수에서 알린 무리”처럼 출처별 문구를
한 단계 더 나눈다.

외교 귀띔처럼 마을 밖에서 온 조기 정보는 파수꾼이 직접 보았다고 꾸미지 않는다.
먼저 전달자의 소문/로그가 나오고, 습격대가 실제 근접 감지선에 들어오는 순간에만
파수꾼이 외친다. 이를 위해 `spotted`와 별도로 습격 인스턴스별 `proximityAlerted`
또는 동등한 1회 키를 저장한다. 경보 출처에 따라 말풍선이 알려 주는 정보도
`방향만 → 세력 추정 → 세력과 대략 규모` 순으로 제한한다.

## 1. 역사 시계 — 부 승격 후 9년, 3막

승격 연도를 T0으로 하는 상대 연표. 각 막 전환은 "최소 연차 도달 + 연간 역사 전환
적용"으로 진행되며 저장에 기록된다. **비트 없는 해가 없다**는 원칙은 유지하되,
여러 팝업을 뜻하지 않는다. 매년 영속적으로 바뀌는 역사 상태는 하나이고 그 원인과
결과가 여러 기존 채널에서 보인다.

**시계의 주어는 인물이다.** 모든 비트가 이름으로 온다 — "여진이 강해진다"가 아니라
"○○가 △△ 부락을 아울렀다더라". 외교 인물 계획이 심어 둔 지도자들이 그대로
배역이 된다.

| 막 | 연차 | 연간 역사 전환 | 주된 징후·흔적 |
|---|---|---|---|
| 1막 패권 | T+1 | **계승자 공인** — 패자 세력의 지도자가 죽고 젊고 강성한 계승자(칸 후보)가 선다 | 이름을 단 계승 소문 · 초상/호칭/말투 교체 · 계승 사절 또는 방문객 |
| 1막 패권 | T+2 | **첫 인접 부락 병합** | 영역·깃발·활동대 소속 변화 · 출신지가 표시된 피난민 · 말/모피 시세 변동 |
| 1막 패권 | T+3 | **지역 패권 재편** | NPC끼리의 참전 결과 · 외교 활동 A6 요청 0~1회 · 흡수되거나 살아남은 거주지의 흔적 |
| 2막 통일 | T+4 | **△△의 칭칸(稱汗)** | 칭칸 대형 이벤트 · 칸의 새 호칭/문체 · 통합 세력의 깃발과 대표 교체 |
| 2막 통일 | T+5 | **공물·군역 질서 수립** | 조정과 칸 양측 사절 · 순찰/보급 활동대 · 제한된 말·철·곡물 시세 변화 |

| 3막 남침 | T+8 | **전선 형성** | 전선 회랑 이동 · 북병사 명의 근왕 교지 · 통행 위기 또는 전란 파급전 |
| 3막 남침 | T+9 | **전쟁의 귀결** | 커밋 노선의 결말 공성/엔딩 · 무커밋 정사 회고 · 지역에 남은 흔적 |

### 1-1. 한 해의 표시 리듬

한 역사 전환은 다음 네 단계로 표시한다.

1. **징후 2~4개** — H0 주민 말풍선 소문, 활동대 이동, 시세, 방문객 등 비모달
   신호가 먼저 온다.
2. **전환 1개** — 계승·병합·칭칸처럼 저장에 남는 세계 상태가 바뀐다. 대형 모달은
   계승·칭칸·최종 커밋처럼 정말 필요한 장면에만 쓴다.
3. **선택 접점 0~1개** — 기존 외교나 통행 위기로 개입할 수 있다. 응답하지 않아도
   NPC 기본 해소가 있고 관계 페널티가 없다.
4. **연말 연대기 1개** — 원인, 결과, 플레이어가 개입했는지 여부와 지역에 남은
   흔적을 기록한다.

즉, `이벤트 4개`가 아니라 **세계 상태 1개가 지도·주민·시장·인물·연대기에서
각기 다르게 보이는 것**이 목표다. 9년 동안 플레이어에게 직접 오는 정치 제안은
총 3~4회를 상한으로 삼는다.

- 3막 종료(T+9) 후에도 게임은 계속된다. 분기하지 않은 경우 정사 엔딩 마감이
  가능해진다 (§4).
- 연차는 초안이다. 구현 시 부 승격의 평균 도달 연차와 저울질해 ±2년 조정 가능.
  다만 "한 막 3년" 골격과 밀도 원칙은 유지할 것.
- 계승자의 이름·성향도 시드 결정적(인물 계획 §0-3의 생성기 재사용). 성향은 연출
  전용 원칙을 유지하되, 칸 후보만은 예외적으로 "강성" 계열에서 뽑는다 — 통일하는
  자의 얼굴이 온화하면 서사가 서지 않는다.

## 2. 패자(覇者) — 통일 세력과 그 인물

역사의 후금/청을 고정 등장시키지 않는다. **그 월드의 여진 세력 중 하나가 패자가
되고, 그 세력의 계승 지도자가 칸이 된다.**

- 후보 세력: 부족 지도자를 가진 5세력 (오도리 씨족·올량합 부락·골간 우디캐·
  니마차 우디캐·홀라온 야인 — 인물 계획 §1과 동일 목록). 만상·송상(조선 상단)과
  변경 마적(혼성 무장 집단)은 후보가 아니다.
- 선정 기준: T0 시점 **현존 최대 세력** (규모 기준, 우호도 아님). 동률이면 세력 id
  오름차순 — 어떤 경우에도 결정적이다.
- **칸은 계승자다.** 1막 개막의 계승 사건으로 등장한 새 지도자가 2막에서 칸을
  칭한다. 이름·초상은 등극 후에도 바뀌지 않는다(인물 계획 §3-1) — 몇 년 소문으로
  듣던 얼굴이 칸이 되는 것이 이 설계의 결정적 장면이다.
- **인물은 세월과 선택을 기억한다.** 계승자에게 별도 관계 게이지는 만들지 않지만,
  해마다 호칭·대사·부관·상처 같은 연출 상태가 누적된다. 플레이어가 예물을 보냈거나,
  참전을 거절했거나, 통행을 허가한 사실도 대사와 연대기에 남는다. 거절의 기억은
  수치 페널티가 아니라 이후 대사의 맥락이다.
- 플레이어와 패자의 우호도는 **세력 우호도를 그대로 승계**한다 (인물별 게이지
  없음 원칙 유지). 계승 직전까지 옛 지도자와 쌓은 관계도 세력 수치이므로 계승으로
  증발하지 않는다 — 1막부터 공을 들이면 된다.
- 엣지 케이스: 후보 5세력이 전부 소멸한 월드에서는 1막 시작 시 외부에서 새 패자
  인물이 등장한다(우호도 0 시작). 원정으로 모든 세력을 지웠어도 귀부 루트가
  성립해야 "원하는 엔딩으로 갈 수 있다"가 지켜진다.
- 1막 동안 패자가 인접 세력을 단계적으로 흡수한다. 흡수된 세력의 지도자는 항복·
  전사·망명 중 결정적 결말을 맞고, 그 결과가 이름을 단 소문과 연대기에 남는다.
  흡수는 지도·영역·거주지 깃발·활동대·교역 대상 목록에 실제로 반영한다. 폐허가 된
  거주지, 살아남아 깃발만 바뀐 거주지, 우회하게 된 교역로 중 하나를 **지역의 흔적**으로
  남기되 세력 AI 전면 개편은 하지 않는다 (§8 비범위).

## 3. 노선과 조건

조건 수치는 구현 시 조정하되, 축은 아래로 고정한다. 모든 축은 기존 시스템의
누적값이다 — 새 게이지를 만들지 않는다.

| 노선 | 성격 | 조건 축 | 게이트 | 성공 엔딩 | 실패(배드) |
|---|---|---|---|---|---|
| **정사** | 정사 | 없음 (무커밋 기본) | 없음 | 호란기를 버텨낸 북방 고을 — 새 질서 아래 존속 | 없음 (커밋이 없으므로) |
| **근왕** | 대체 | 조정 관계 高(세공 성실·하사 이력) + 군사력 | 3막 근왕 교지 | 북방에서 남침을 꺾어 역사가 갈라진다 | 방어전 패배 → 함락 |
| **귀부** | 대체 | 패자 우호 高 + 조정 관계 低 | 2막 귀부 사절 | 신흥 왕조의 번(藩)으로 번영 | 선봉으로 소모·통일 후 숙청 |
| **개국** | 대체 | 군사+경제+인구 최상위 + 조정 관계 低 | 3막 능동 선포 | 북방 신생국 개창 | 토벌군·패자 양면 협격 → 멸망 |

- **게이트 형태**: 근왕·귀부는 조건 충족 시 이벤트(교지/사절)로 제안이 온다.
  개국만 플레이어의 능동 선택 — 관청 메뉴에 조건 충족 시 항목이 활성화된다.
  (반역은 제안받는 것이 아니라 저지르는 것이다.)
- **커밋 고지**: 수락 버튼에는 해당 노선이 요구할 수 있는 의무와 실패 위험을
  자연어로 표시한다. 예를 들어 근왕은 "훗날 병력과 방어를 요구받을 수 있다",
  개국은 "조정과 패자 모두가 적이 될 수 있다"까지 알려 준다. 숨기는 것은 수치이지
  약속의 의미가 아니다.
- **모든 게이트에 얼굴이 있다**: 근왕 교지와 토벌군은 **현임 북병사** 명의·지휘다
  (개국·근왕 실패 방어전의 조정측 상대에게 이름이 생긴다). 귀부 사절은 **칸** 명의로
  오고, 수락 연출에 정략혼 일회성 이벤트가 붙는다(§9-3). 게이트 대사의 조건 암시도
  인물 성향 문체를 탄다.
- **조건 축의 능동 레버 = 외교 활동**: 패자 우호는 예물(A1·구현됨)·화친 맹약(A2)·
  참전(A6, 1막에서 △△ 편 참전 = 귀부 가속, 반대편 = 귀부 차단에 가까움)으로
  움직이고, 그 대가인 의심 상승이 조정 관계 축과의 트레이드오프를 만든다.
  외교 활동 없이 교역만으로도 조건 도달은 가능해야 한다 (활동은 가속이지 필수가
  아니다 — §0-1).
- **커밋의 배타성**: 한 노선에 커밋하면 다른 게이트는 닫힌다. 커밋 전에는 제안을
  거절하거나 무시해도 관계·거래·엔딩 접근 불이익이 없다. 같은 막 안에서 조건이
  유지되면 제안은 한 번 더 올 수 있다. 인물은 거절을 대사와 연대기로만 기억한다.
- **조건 암시**: 수치를 보여주지 않는 대신, 사절·소문 대사로 간접 암시한다.
  (예: 귀부 조건에 못 미치면 사절이 "칸께서 그대의 이름을 아직 모르신다"류의
  대사로 돌아간다.) 충족/미충족이 대사 분기로 드러나는 수준까지만.
- **정사 엔딩의 마감**: 무커밋으로 3막이 끝나면 관청 "연대기 마감"이 열리고,
  원하는 때에 정사 엔딩으로 마감할 수 있다. 전란 파급전의 승패는 이 기능을 잠그지
  않는다. 마감하지 않으면 영원히 계속 플레이.
- **정사도 완전한 이야기다**: 무커밋은 콘텐츠를 놓친 실패 경로가 아니다. 어떤
  정치적 이름도 걸지 않고 주민과 터전을 지켜 낸 변경의 생존사로 연출한다. 받아들인
  피난민, 흘려보낸 군대, 겪은 파급전, 살아남은 거주지가 정사 회고의 핵심 재료다.

### 3-1. 새 칸의 협정 계승 심사

2막의 **옛 맹약·협정 일괄 무효**는 삭제한다. 새 질서는 기존 관계를 다음처럼
승계하거나 중립적으로 정리한다.

- 개인적 은혜·원한과 예물 이력은 인물 기억과 세력 관계에 남는다.
- 영유 합의는 실제 경계가 바뀌지 않는 한 자동 유지한다.
- 군사 맹약은 일정 기간 **계승 유예**가 된다. 유예 중 재체결하면 혜택이 이어진다.
- 재체결하지 않거나 요청을 무시하면 유예 종료 뒤 중립 관계로 끝난다. 적대 전환,
  관계 감소, 보복 습격은 없다.

재체결은 혜택을 이어 가기 위한 선택이지, 중립을 유지하기 위한 의무가 아니다.

## 4. 전란과 방어전 — 세계 전란, 파급전, 결말 공성

후반 전쟁을 세 층으로 분리한다. **전란 자체는 모두에게 오지만, 멸망을 건 결말
공성은 명시적으로 약속한 플레이어에게만 온다.** 정착지 규모 기반 침공 판정은
성공한 플레이어를 벌주는 효과가 있으므로 삭제한다.

### 4-1. 0층 — 세계 전란 (항상)

플레이어의 선택과 무관하게 패자의 영역이 넓어지고 전선이 남하한다. 영역·깃발·
활동대·봉수·피난민·시장 가격·NPC끼리의 전투 결과가 바뀌며 연대기에 기록된다.
플레이어는 관찰만 해도 되고, 기존 외교·교역·원병 활동으로 개입해도 된다.

### 4-2. 1층 — 전란 파급전 (모든 노선에서 가능)

기존 습격 체계를 재사용해 약탈대·정찰대·보급대·후퇴 병력·패잔병이 출현한다.
이들은 정착지를 멸망시키러 오는 결말군이 아니라 전쟁 때문에 길과 식량을 찾는
부대다.

- **두 단계 예고**: `북방 대군 집결` 같은 전략 경보 뒤, 며칠·몇 주 후
  `서쪽 계곡으로 약탈대 접근` 같은 전술 경보를 내고 실제 전투를 시작한다.
- **상한**: 전력과 피해 규모는 기존 일반 습격의 후반 상한 안에 둔다. 패배 결과는
  창고 일부 약탈, 가축 손실, 외곽 시설 피해, 일시적 시세 변화까지다.
- **실패 전진**: 파급전에서 져도 게임오버·엔딩 잠금·노선 잠금이 없다. 결과를
  연대기와 지역 흔적으로 남기고 시계는 계속 간다.
- **별도 임무가 아님**: 전란 파급전은 기존 방어·습격 플레이에 역사적 원인과
  이름을 부여한 것이다. 정해진 원정이나 외교 심부름을 수행해야 막을 수 있게 하지
  않는다.

### 4-3. 전선 회랑과 통행 위기

대군과 파급 부대는 임의 목표나 정착지 규모가 아니라 **전선 회랑**을 따라 이동한다.
회랑은 강·협곡·평야·교역로·고개처럼 현재 지도에서 계산 가능한 통행 비용과 기존
경로 탐색으로 결정한다.

- 회랑에 가까운 거점은 봉수·통행 부대·파급전을 더 직접 경험한다.
- 회랑에서 먼 거점은 주력이 아니라 소규모 약탈대·피난민·시세로 전란을 경험한다.
- 회랑은 전란의 강도와 표현만 바꾸며 엔딩 조건이나 노선 접근을 잠그지 않는다.
  같은 시드에서는 같은 회랑이 나와야 한다.

중립 거점이 회랑을 막으면 자동 대공성 대신 **통행 위기**가 온다.

1. **통행 허가** — 중립 유지, 대군 통과, 제한된 시세·지역 영향.
2. **대피** — 창고 일부를 옮기고 외곽 피해를 감수하되 공성 없음.
3. **저지** — `중립을 포기하고 전쟁에 개입한다`는 확인 뒤 결말 공성 가능.
4. **무응답** — 기한 뒤 현지 관리가 통행을 허가한 것으로 자동 처리. 관계 페널티와
   공성 없음.

### 4-4. 2층 — 결말 공성 (커밋 노선)

근왕 약속, 개국 선언, 귀부 뒤 명시적 배신, 통행 저지, 선제공격처럼 플레이어가
전쟁에 이름을 건 경우에만 3~5웨이브 결말 공성이 발생한다. 노선에 따라 규모를
차등한다. 개국은 토벌군과 패자 양쪽을 상대할 수 있다.

- **휴지기**: 웨이브 사이에 전략 화면으로 복귀한다. 며칠의 간격 동안 수리·재배치·
  치료·**저장**이 가능해야 한다.
- **실패의 단계성**: 웨이브 하나를 진다고 즉시 게임오버가 아니다. 피해를 안고
  다음 웨이브로 이어지며 최종 함락 시에만 커밋 실패 악결말이 성립한다.
- **인물 주체**: 칸 또는 현임 북병사의 이름·초상·성향 문체가 전략 경보, 항복 권고,
  웨이브 사이 교섭, 최종 결과에 계속 등장한다.

## 5. 엔딩 처리와 연출

- **굿엔딩**: 연대기 회고 연출(연도별 주요 사건을 훑는 두루마리형 화면) + 기록 →
  계속 플레이 복귀. 이후 언제든 "연대기 마감"으로 공식 종료.
- **배드엔딩**: 함락/멸망 연출 후 게임오버. 기존 게임오버 처리 재사용.
- **기록**: 도달한 엔딩은 저장 파일에 남긴다 (연대기 화면에서 재열람).
- 연출은 신규 일러스트 없이 기존 스프라이트·지도 연출과 텍스트, 그리고 **인물
  초상**(인물 계획 §3-1의 풀)으로 구성한다. 칭칸·귀부 사절·근왕 교지·토벌 장면에
  칸/북병사 초상을 쓴다 — 등극해도 초상이 바뀌지 않는 규칙 덕에 별도 아트가
  필요 없다.

## 6. 저장 스키마

말풍선 소문망은 역사 시계보다 먼저 시작하므로 `state.endgame` 밖에 둔다. 현재 떠
있는 말풍선 자체는 저장하지 않고 일정·반복 방지·중요 소문 전달 여부만 저장한다.

```ts
interface AmbientSpeechState {
  lastProcessedDay: number;
  consumedSlotIds: string[];       // 날짜+슬롯, 저장/로드 후 재발화 방지
  deliveredRumorIds: string[];     // 전쟁·부임·역사 예고의 중복 방지
  handledUrgentIds: string[];      // 습격 발견 등 슬롯 밖 긴급 외침 중복 방지
  recentLineIds: { id: string; day: number }[]; // 문구/사실 냉각용, 기간 밖 항목 정리
}
```

`state.endgame` (신규, 마이그레이션 1회):

```ts
interface EndgameState {
  clockStage: 0 | 1 | 2 | 3;      // 0 = 미시작(부 이전), 1~3 = 막
  stageStartYear: number;          // 현재 막의 시작 연도
  clockYear: number;               // T0 기준 현재 연차, 저장/로드 후 전환 중복 방지
  appliedTransitionIds: string[];  // 연간 역사 전환 적용 이력
  emittedSignalIds: string[];      // 징후·선택 접점·연대기 중복 방지
  overlordFactionName: string | null; // 패자 세력 (외부 등장 세력 포함)
  // 칸 후보 → 칸. 1막 계승 사건에서 생성되는 인물 — factionLeaders의 해당 항목을
  // 이 인물로 교체한다 (인물 계획의 지도자 저장 구조 재사용, 초상 배정도 동일 규칙).
  khan: { name: string; title: string } | null;
  absorbedFactionNames: string[];  // 1막에서 흡수된 세력
  actorMemories: { actorKey: string; kind: string; year: number }[];
  pactSuccession: {
    factionName: string;
    kind: 'personal' | 'territorial' | 'military';
    status: 'inherited' | 'grace' | 'renewed' | 'neutral-ended';
  }[];
  committedRoute: 'loyalist' | 'submission' | 'founding' | null;
  gateHistory: { route: string; year: number; accepted: boolean }[];
  frontCorridorKey: string | null; // 같은 시드·상태에서 같은 회랑을 재구성하는 키
  passageCrisis: {
    status: 'pending' | 'allowed' | 'evacuated' | 'resisted' | 'expired';
    deadlineDay: number;
  } | null;
  achievedEnding: string | null;   // 재열람·연대기 마감용
  invasionWave: number | null;     // 방어전 진행 중일 때
}
```

## 7. 구현 단계 (비용 분할 — 전투가 가장 비싸므로 뒤로)

단계 접두는 H(history)다 — 외교 활동 계획의 E 단계와 혼동하지 않게.

| 단계 | 내용 | 완료 기준 |
|---|---|---|
| H0 | 주민 말풍선 소문망 — 하루 2슬롯·화자 선정·상태/정세/습격 조짐 공급자·파수꾼 긴급 외침·반복 냉각·로그 병기 | 3일 방치에서 화면 내 주민이 과밀 없이 잡담하며, 외교 예고·마을 상태·습격 조짐·출처별 조기 정보·실제 근접 경보가 정보 단계와 화자를 지켜 한 번씩만 나온다 |
| H1 | 역사 상태 머신 + 패자·계승자 생성 + 연간 리듬 + 1~2막의 영역·깃발·활동대·시세·피난민 반응 + 인물 기억 | 부 승격 후 방치 플레이에서 연간 전환이 중복 없이 이어지고, 하나의 전환이 여러 채널에 이름 있는 결과를 남긴다 |
| H2 | 게이트·조건 판정 + 커밋 고지 + 협정 계승 심사 + **전투 없는 노선**(귀부 성공/실패, 정사 마감) | 귀부와 정사 엔딩을 처음부터 끝까지 볼 수 있고, 제안 무시·협정 미갱신이 적대나 엔딩 잠금을 만들지 않는다 |
| H3 | 세계 전란·파급전·결말 공성 3층 + 결정적 전선 회랑 + 통행 위기 + 근왕·개국·배드엔딩 | 중립은 예고된 파급전을 겪고도 정사로 진행하며, 명시적 저지/커밋에서만 다중 웨이브와 악결말 위험이 열린다 |
| H4 | 지역 흔적·후계자 성장 연출·초상 활용 + 조건 암시 대사 + 기록/재열람 | 전 노선 회귀와 9년 방치 회귀에서 팝업 과밀·신호 중복·저장 복원이 함께 검증된다 |

H0는 부 승격 이전의 평시 플레이에서도 동작하는 공통 기반이다. H1은 역사 징후를
H0 공급자로 등록하며, H1~H2까지만으로도 "정세가 흘러가고, 귀부와 정사 엔딩이
있는" 완결된 중간 상태가 된다. H3은 별도 작업자가 이어받아도 되는 독립 덩어리다.

### 7-1. H1 필수 범위

- [ ] 연도·막·패자·계승자·커밋만으로 시작하는 역사 상태 머신
- [ ] `전환 1 + 징후 2~4 + 선택 0~1 + 연대기 1` 공통 스케줄러
- [ ] 영역·거주지 깃발·활동대·시장·피난민을 연결하는 역사 반응 어댑터
- [ ] 후계자의 호칭·문체·플레이어 선택 기억(관계 수치와 분리)
- [ ] 협정 계승 심사에 필요한 저장 계약과 마이그레이션 기반

전선 회랑·통행 위기·다중 웨이브는 설계와 저장 자리를 H1에서 고정하되 실제
시뮬레이션은 H3에서 구현한다. H1에 전쟁 전체를 끌어오지 않는다.

## 8. 비범위 (하지 말 것)

- 세력 AI 전면 개편 — 흡수·통일은 이벤트와 데이터 변경으로 표현한다.
  세력 간 실시간 전쟁 시뮬레이션을 만들지 않는다.
- 특정 실존 국호("후금"·"청")·실존 인물("누르하치")의 고정 등장 — 패자는 그
  월드의 세력이고, 칸은 그 월드의 인물이다.
- 확률 게이트 — 조건 판정·패자 선정·침공 시점 어디에도 난수를 넣지 않는다
  (전투 내부의 기존 난수는 예외 — 그것은 플레이어가 개입하는 영역이다).
- 조건 수치의 UI 노출 — 암시는 대사 분기까지만.
- 부 승격 이전 플레이 변경 — 이 설계 전체가 T0 이후에만 존재한다.
- 별도 역사 퀘스트·심부름 목록 — 기존 외교·교역·방어 행동으로만 개입한다.
- 매년 2~4개의 강제 모달 — 대형 모달은 계승·칭칸·커밋·결말에 한정한다.
- 절차 지형으로 엔딩 접근을 잠그는 판정 — 전선 회랑은 전란의 표현과 강도만
  바꾸며 원하는 노선의 결정적 도달 가능성을 훼손하지 않는다.

## 9. 열린 문제 (구현 전 확정 필요)

1. 조건 축별 구체 수치 — 각 축의 분포를 실플레이 데이터로 확인 후 확정.
   엔딩 판정의 축은 고정됐고 수치 튜닝만 남음.
2. 귀부 이후의 계속 플레이 상태 — 세공 대상이 조정에서 패자로 바뀌는가,
   교역·하사는 어떻게 되는가. E2에서 결정.
3. 정략혼 — 외교 활동 계획(DESIGN-2026-07-30-diplomatic-actions.md)에서 상시
   활동으로는 보류하고, **귀부 루트의 일회성 이벤트**로 여기 편입하기로 확정
   (2026-07-30). 게이트 수락 연출 또는 조건 보조로 쓴다 — 형태는 E2에서 결정.
4. 파급전 피해 상한 — 기존 일반 습격의 후반 분포를 측정해 창고·가축·외곽 시설
   손실의 최대치를 확정. 정사 마감과 엔딩 접근에는 영향을 주지 않는다.
5. 지역 흔적의 자산 범위 — H1은 깃발·상태·로그 재사용으로 시작하고, 폐허 변형과
   교역로 표시는 H4에서 필요한 만큼만 추가한다.
