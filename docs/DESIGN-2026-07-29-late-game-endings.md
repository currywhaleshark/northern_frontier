# 후반 엔딩 — 북방 통일 전쟁과 연대기의 갈래 (설계)

> **계획 상태:** 보류
> **상태 갱신:** 2026-07-29 — 역사 시계의 진행 방식을 확정할 때까지 구현을 보류한다.

- 작성: 2026-07-29
- 전제: 부(府) 승격 이후의 장기 플레이에 서사적 목적지를 만든다.
  기존 부 승격 엔딩("맞거나 계속")은 그대로 두고, 그 뒤의 이야기다.

## 0. 원칙 (전 항목에 우선)

1. **조건은 비공개, 판정은 결정적.** 엔딩 조건을 UI에 나열하지 않는다.
   그러나 조건을 아는 플레이어는 반드시 원하는 엔딩에 도달할 수 있어야 한다 —
   난수가 엔딩을 막는 설계(확률 게이트, 월드 생성 복권)는 금지.
2. **계속 플레이가 기본값.** 조건을 충족해도 커밋은 항상 선택이다. 거절하거나
   무시하면 아무 일도 없이 계속 플레이. 커밋하지 않은 플레이어에게 배드엔딩을
   강제하지 않는다.
3. **배드엔딩 = 커밋한 노선의 실패**이며 게임오버다(기존 중심지 함락과 동일 처리).
   실패 판정도 난수가 아니라 준비도와 전투 결과로 결정된다.
4. **굿엔딩 후에는 계속 플레이할 수 있다.** 엔딩 연출을 본 뒤 샌드박스로 복귀하고,
   이후 관청 메뉴의 "연대기 마감"으로 **원하는 때에 언제든** 공식 종료(엔딩 재연출 +
   기록 화면)를 할 수 있다.
5. **역사 시계는 보이게, 조건은 숨기게.** 정세의 진행(누가 강해지는가, 전쟁이
   어디까지 왔는가)은 소문·사절·시세로 계속 노출한다. 조건을 아는 플레이어가
   "언제까지 무엇을 준비해야 하는지"를 게임 안에서 읽을 수 있어야 한다.

## 1. 역사 시계 — 부 승격 후 9년, 3막

승격 연도를 T0으로 하는 상대 연표. 각 막 전환은 "최소 연차 도달 + 전환 이벤트
발화"로 진행되며 저장에 기록된다. 밀도 원칙: **비트 없는 해가 없다** (연 2~4회).

| 막 | 연차 | 정세 | 대표 비트 (연 2~4회) |
|---|---|---|---|
| 1막 패권 | T+1~T+3 | 부족 전쟁 격화, 패자 후보 부상 | 상단이 전하는 전황 소문 · 인접 세력 흡수(세력 지도 변화) · 피난민 무리 유입 · 말/모피 시세 변동 |
| 2막 통일 | T+4~T+6 | 통일 전쟁 종결, 국호 선포 | 국호 선포(대형 이벤트) · 조정의 세공 인상과 군역 요구 · 패자의 사절 왕래 · **1차 게이트** |
| 3막 남침 | T+7~T+9 | 남침 개시 | 봉수 연기(침공 경보) · 근왕 교지 · **최종 게이트** · 방어전/엔딩 분기 |

- 3막 종료(T+9) 후에도 게임은 계속된다. 분기하지 않은 경우 정사 엔딩 마감이
  가능해진다 (§4).
- 연차는 초안이다. 구현 시 부 승격의 평균 도달 연차와 저울질해 ±2년 조정 가능.
  다만 "한 막 3년" 골격과 밀도 원칙은 유지할 것.

## 2. 패자(覇者) — 통일 세력의 선정

역사의 후금/청을 고정 등장시키지 않는다. **그 월드의 여진 세력 중 하나가 패자가
된다.**

- 선정 기준: T0 시점 **현존 최대 세력** (규모 기준, 우호도 아님). 동률이면 세력 id
  오름차순 — 어떤 경우에도 결정적이다.
- 플레이어와 패자의 우호도는 **기존 우호도를 그대로 승계**한다. 1막부터 패자가
  누구인지 소문으로 드러나므로, 귀부를 노리는 플레이어는 그때부터 공을 들이면 된다.
- 엣지 케이스: 여진 세력이 전부 소멸한 월드에서는 1막 시작 시 외부에서 새 패자가
  등장한다(우호도 0 시작). 원정으로 모든 세력을 지웠어도 귀부 루트가 성립해야
  "원하는 엔딩으로 갈 수 있다"가 지켜진다.
- 1막 동안 패자가 인접 세력을 단계적으로 흡수한다. 흡수는 지도·교역 대상 목록에
  실제로 반영하되, 세력 AI 전면 개편은 하지 않는다 (§8 비범위).

## 3. 노선과 조건

조건 수치는 구현 시 조정하되, 축은 아래로 고정한다. 모든 축은 기존 시스템의
누적값이다 — 새 게이지를 만들지 않는다.

| 노선 | 성격 | 조건 축 | 게이트 | 성공 엔딩 | 실패(배드) |
|---|---|---|---|---|---|
| **정사** | 정사 | 없음 (무커밋 기본) | 없음 | 호란기를 버텨낸 북방 고을 — 새 질서 아래 존속 | 없음 (커밋이 없으므로) |
| **근왕** | 대체 | 조정 관계 高(세공 성실·하사 이력) + 군사력 | 3막 근왕 교지 | 북방에서 남침을 꺾어 역사가 갈라진다 | 방어전 패배 → 함락 |
| **귀부** | 대체 | 패자 우호 高 + 조정 관계 低 | 2막 귀부 사절 | 신흥 왕조의 번(藩)으로 번영 | 선봉으로 소모·통일 후 숙청 |
| **개국** | 대체 | 군사+경제+인구 최상위 + 조정 관계 低 | 3막 능동 선포 | 북방 신생국 개창 | 토벌군·패자 양면 협격 → 멸망 |

- **게이트 형태**: 근왕·귀부는 조건 충족 시 이벤트(교지/사절)로 제안이 온다.
  개국만 플레이어의 능동 선택 — 관청 메뉴에 조건 충족 시 항목이 활성화된다.
  (반역은 제안받는 것이 아니라 저지르는 것이다.)
- **커밋의 배타성**: 한 노선에 커밋하면 다른 게이트는 닫힌다. 커밋 전에는 제안을
  거절해도 불이익 없음 — 같은 막 안에서 조건이 유지되면 제안은 한 번 더 온다.
- **조건 암시**: 수치를 보여주지 않는 대신, 사절·소문 대사로 간접 암시한다.
  (예: 귀부 조건에 못 미치면 사절이 "칸께서 그대의 이름을 아직 모르신다"류의
  대사로 돌아간다.) 충족/미충족이 대사 분기로 드러나는 수준까지만.
- **정사 엔딩의 마감**: 무커밋으로 3막이 끝나면(침공 경로 여부에 따라 방어전을
  치렀을 수도 있다) 관청 "연대기 마감"이 열리고, 원하는 때에 정사 엔딩으로 마감할
  수 있다. 마감하지 않으면 영원히 계속 플레이.

## 4. 침공과 방어전 — 다중 웨이브

근왕 커밋, 개국 커밋, 그리고 무커밋이라도 침공 경로에 걸린 경우 방어전이 발생한다.

- **침공 경로 판정은 규모 기반.** 마을 규모(인구+경제)가 문턱을 넘으면 패자의
  남침 경로에 오른다 — 크면 표적이 된다. 지리 기반은 월드 생성 난수가 결과를
  갈라 §0-1에 어긋나므로 쓰지 않는다. 문턱 아래로 조용히 사는 무커밋 마을은
  전화를 비껴가고 정사 엔딩으로 향한다.

- **구조**: 전술 전투를 재사용한 3~5 웨이브. 노선에 따라 규모 차등
  (무커밋 < 근왕 < 개국 — 개국은 토벌군과 패자 양쪽을 상대한다).
- **휴지기**: 웨이브 사이에 전략 화면으로 복귀한다. 며칠의 간격 동안 수리·재배치·
  치료·**저장**이 가능하다. 유저 요구사항: 숨 돌릴 틈과 저장할 틈은 반드시 준다.
- **실패의 단계성**: 웨이브 하나를 진다고 즉시 게임오버가 아니다. 건물 피해와
  사상자를 안고 다음 웨이브로 이어지며, **최종 함락 시에만** 배드엔딩.
- 무커밋 방어전에서 마을이 함락되면 — 이것은 커밋 실패가 아니라 기존의 중심지
  파괴 게임오버와 동일한 사건이다. §0-2와 모순되지 않는다 (방비는 늘 플레이어의
  몫이었다).

## 5. 엔딩 처리와 연출

- **굿엔딩**: 연대기 회고 연출(연도별 주요 사건을 훑는 두루마리형 화면) + 기록 →
  계속 플레이 복귀. 이후 언제든 "연대기 마감"으로 공식 종료.
- **배드엔딩**: 함락/멸망 연출 후 게임오버. 기존 게임오버 처리 재사용.
- **기록**: 도달한 엔딩은 저장 파일에 남긴다 (연대기 화면에서 재열람).
- 연출은 신규 일러스트 없이 기존 스프라이트·지도 연출과 텍스트로 구성한다.

## 6. 저장 스키마

`state.endgame` (신규, 마이그레이션 1회):

```ts
interface EndgameState {
  clockStage: 0 | 1 | 2 | 3;      // 0 = 미시작(부 이전), 1~3 = 막
  stageStartYear: number;          // 현재 막의 시작 연도
  overlordFactionId: number | null; // 패자 (외부 등장 세력 포함)
  absorbedFactionIds: number[];    // 1막에서 흡수된 세력
  committedRoute: 'loyalist' | 'submission' | 'founding' | null;
  gateHistory: { route: string; year: number; accepted: boolean }[];
  achievedEnding: string | null;   // 재열람·연대기 마감용
  invasionWave: number | null;     // 방어전 진행 중일 때
}
```

## 7. 구현 단계 (비용 분할 — 전투가 가장 비싸므로 뒤로)

| 단계 | 내용 | 완료 기준 |
|---|---|---|
| E1 | 역사 시계 + 패자 선정 + 1~2막 비트(소문·흡수·시세·피난민) | 부 승격 후 방치 플레이에서 9년간 비트가 끊기지 않는다 |
| E2 | 게이트·조건 판정 + 커밋 + **전투 없는 노선** (귀부 성공/실패, 정사 마감, 연대기 화면) | 귀부 엔딩을 처음부터 끝까지 볼 수 있다 |
| E3 | 다중 웨이브 방어전 + 근왕·개국 + 배드엔딩 | 근왕 성공·실패, 개국 성공·실패 도달 가능 |
| E4 | 연출 다듬기 + 조건 암시 대사 + 기록/재열람 | 전 엔딩 회귀 확인 |

E1~E2까지만으로도 "정세가 흘러가고, 귀부와 정사 엔딩이 있는" 완결된 중간 상태가
된다. E3은 별도 작업자가 이어받아도 되는 독립 덩어리다.

## 8. 비범위 (하지 말 것)

- 세력 AI 전면 개편 — 흡수·통일은 이벤트와 데이터 변경으로 표현한다.
  세력 간 실시간 전쟁 시뮬레이션을 만들지 않는다.
- 특정 실존 국호("후금"·"청")의 고정 등장 — 패자는 그 월드의 세력이다.
- 확률 게이트 — 조건 판정·패자 선정·침공 시점 어디에도 난수를 넣지 않는다
  (전투 내부의 기존 난수는 예외 — 그것은 플레이어가 개입하는 영역이다).
- 조건 수치의 UI 노출 — 암시는 대사 분기까지만.
- 부 승격 이전 플레이 변경 — 이 설계 전체가 T0 이후에만 존재한다.

## 9. 열린 문제 (구현 전 확정 필요)

1. 조건 축별 구체 수치 — 각 축의 분포를 실플레이 데이터로 확인 후 확정.
   (침공 경로의 규모 문턱 포함 — §4에서 규모 기반으로 확정, 수치만 남음)
2. 귀부 이후의 계속 플레이 상태 — 세공 대상이 조정에서 패자로 바뀌는가,
   교역·하사는 어떻게 되는가. E2에서 결정.
3. 정략혼 — 외교 활동 계획(DESIGN-2026-07-30-diplomatic-actions.md)에서 상시
   활동으로는 보류하고, **귀부 루트의 일회성 이벤트**로 여기 편입하기로 확정
   (2026-07-30). 게이트 수락 연출 또는 조건 보조로 쓴다 — 형태는 E2에서 결정.
