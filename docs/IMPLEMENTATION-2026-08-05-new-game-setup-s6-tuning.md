## 1. 목표와 범위

잠겨 있던 **시작 물자 / 통합 자원 밀도 / 기후 혹독도 / 위협** 3단계 선택을 활성화한다.
난이도 카드는 네 값을 한 번에 고르는 프리셋이고, 한 항목이라도 직접 바꾸면
`difficultyPreset = 'custom'`으로 저장한다. 지역과 지도 크기는 계속 별도 선택이다.

## 2. 구현 계약

### S6-1. 옵션과 UI

- 프리셋 선택은 네 노브와 `baseDifficulty`를 함께 바꾼다.
- 개별 선택은 `baseDifficulty`를 유지하고 프리셋 표시만 `사용자 설정`으로 바꾼다.
- 단계 문구는 항목별로 `부족/기준/풍부`, `희소/기준/풍부`, `온화/기준/혹독`,
  `낮음/기준/높음`을 쓴다.
- 시작 시 정규화된 `NewGameOptions` 하나만 전달하며, 시드와 이름의 RNG 격리는 유지한다.

### S6-2. 실효값과 기존 판 보존

- 배율은 시작 시 `worldSetup.effective`에 스냅샷으로 저장한다. 로드 후 CONFIG가 바뀌어도
  이미 시작한 판의 값은 바뀌지 않는다.
- `normal` 프리셋과 구 저장의 실효값 1은 기존 지도·날씨·RNG 순서를 그대로 보존한다.
- 시작 물자는 평판·방어도를 제외한 초기 자원, 위협은 일일 증가와 습격 전력에 적용한다.
  이 두 기존 소비처는 회귀로 고정한다.

### S6-3. 통합 자원 밀도

- 배율은 숲, 보장분을 제외한 지표 광상, 짐승 서식지, 어장, 일반 지하 광맥·수맥에 적용한다.
- 중심지 근처 돌·철 광상과 시작 수맥은 단계와 무관하게 유지한다.
- 지표 밀도 보정은 지도 본 생성 RNG와 분리한 결정적 스트림으로 처리해 `normal` 지도를 바꾸지 않는다.
- 지하 광맥·수맥은 위치를 유지하고 일반 매장 용량만 배율화한다. 캐시 키에 밀도를 포함하며
  건설 판정·채굴·급수·로드 정규화가 같은 밀도를 읽는다.

### S6-4. 기후 혹독도

- 연간 기후의 한랭·건조·폭풍 위험축을 0~1 구간에서 배율화한다. 같은 시드·연도에서
  `온화 ≤ 기준 ≤ 혹독` 순으로 위험이 단조 증가하고 값은 `[-1, 1]`에 고정한다.
- 보정된 연간 기후를 계절 날씨표, 이전 겨울 적설 기반 해빙 홍수, 기후 재해·화재·수자원·
  해상 상태와 측우기 문구가 함께 읽는다.
- `normal` 배율 1은 기존 연간 기후와 날짜별 날씨를 바이트 수준으로 보존한다.
