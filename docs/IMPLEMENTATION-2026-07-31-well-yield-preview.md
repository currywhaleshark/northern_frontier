# 우물 배치 예상 산출 구현계획

> **계획 상태:** 완료
> **상태 갱신:** 2026-07-31 — 배치 커서 툴팁, 실제 급수 계산 재사용, 허생 정보 차등, 표적 회귀와 빌드를 완료했다.

- 담당 모델: `gpt-5.6-terra`
- 추론: `medium`
- 연관 설계: [우물과 급수](DESIGN-2026-07-28-wells-and-water.md) U2

## 범위

- [x] 우물 배치 중 유효 수맥 칸에서 커서 툴팁으로 예상 산출을 표시한다.
- [x] `wellWaterStatusAt`를 배치 표시와 실제 급수 시뮬레이션의 단일 계산 경로로 유지한다.
- [x] 허생이 없으면 수맥 중심·풍부도 수치를 숨기고 정성 안내만 보인다.
- [x] 허생이 있으면 수위와 예상 하루 취수량을 정수로 보인다.
- [x] 무효 배치와 수맥 없음은 기존 배치 가능 판정을 바꾸지 않고 안내만 한다.

## 검증

- `tools/game/test_water_coverage.mjs` — 배치 표시가 실제 우물 산출 계산을 그대로 사용하고 수맥 없음은 산출이 없음을 확인.
- `npm run build` — 타입 검사와 프로덕션 빌드.
