# 재해 확장 구현계획

> **계획 상태:** 완료
> **상태 갱신:** 2026-07-29 — D0 공통 지연 재해 기반과 D1 이른 서리 개편·표적 검증을 완료했다.

- 기준 설계: [재해 확장 설계](DESIGN-2026-07-28-disasters.md)
- 현재 슬라이스: D0+D1
- 원칙: 단계별 표적 테스트만 실행하고, 전체 테스트는 최종 감사에서 교차 시스템 위험이
  확인될 때 한 번만 실행한다.

## 모델 배정

| 단계 | 권장 모델 | 추론 수준 | 이유 |
|---|---|---|---|
| D0 상태·저장·일일 틱 | `gpt-5.6-sol` | high | `GameState`, 저장 스키마, 일일 처리 순서를 함께 바꾸는 교차 시스템 작업 |
| D1 사건 판정·표적 테스트 | `gpt-5.6-terra` | high | 기존 이른 서리 경로를 결정적 날씨 추적으로 바꾸는 한정된 로직 작업 |
| D1 경보·렌더 오버레이 | `gpt-5.6-terra` | medium | 기존 경보·경작지 렌더 패턴을 재사용하는 국소 UI 작업 |
| 최종 감사 | `gpt-5.6-sol` | high | 저장 호환, RNG 비소비, 일일 순서와 회귀 범위를 종합 확인 |

## D0 — 공통 지연 재해 기반

- [x] `DisasterId`, `PendingDisaster`, `GameState.pendingDisasters` 추가
- [x] 새 게임은 빈 배열, 저장 스키마 v44, v43 이하는 빈 배열로 마이그레이션
- [x] `advancePendingDisasters(state)`를 날씨 확정 뒤 일일 처리에 연결
- [x] 진행 중 재해를 상단 경보에 표시
- [x] 저장 왕복·구 저장·결정적 일일 진행 표적 테스트

## D1 — 이른 서리 지연 판정

- [x] 발생 조건을 가을의 실제 서리 날씨에 맞춤
- [x] `조기 수확`은 기존 즉시 수확을 유지
- [x] `기다린다`는 이후 4일간 `frost`·`coldSnap`을 세고 2일 이상이면 성장도 25%만 유지
- [x] 측우기 수치는 실제 주사위가 아니라 기후 기반 근사 예보임을 문구와 테스트에 명시
- [x] 대상 경작지에 판정 기간 동안 백화 오버레이 표시
- [x] 즉시 결과 없음·4일 경계·성공/실패·대상 소멸·중복 방지 표적 테스트

## 검증 기록

- `node tools/game/test_pending_disasters.mjs`
- `node tools/game/test_disaster_climate.mjs`
- `node tools/game/test_resource_save_migration.mjs`

스키마 회귀와 프로덕션 빌드만 한 번씩 검증했다.
