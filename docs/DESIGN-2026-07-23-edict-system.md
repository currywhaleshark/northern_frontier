# 절목(節目) 시스템 — 마을 중심지의 제도·정책 설계안

> **계획 상태:** 완료
> **상태 갱신:** 2026-08-05 — 확정한 7종 절목과 이주·화재·노년·가내수공업·토목 부역 효과를 구현하고 86개 핵심 회귀와 프로덕션 빌드로 검증했다.

- 작성일: 2026-07-23 (명칭 확정 2026-07-25: 법도 → **절목**)
- 발단: "중심지에서 제도 같은 걸 정하는 기능" — 겨울 난방 제한, 식량 배급 조절,
  인구 조절, (화재 실장 시) 내화 규정 등
- 관련: DESIGN-2026-07-23-content-gap-proposals.md (화재·술·명절 제안과 다수 연동)

## 1. 무엇이라 부를 것인가

| 후보 | 뉘앙스 | 판정 |
|---|---|---|
| 정책 | 현대 행정 용어 | 시대감 없음 |
| 제도 | 무난하나 밋밋 | 기각 |
| 향약(鄕約) | 사족 주도의 자치 규약, 도덕 규범 포함 | 군사 개척지 초기엔 이르고, 후반 문화 콘텐츠로 어울림 |
| 법도(法度) | "고을의 법도" — 직관적이나 규범 일반을 뜻해 범위가 넓다 | 차선 |
| 영(令) | 수령·첨사가 내리는 명령. 금주령·절미 등 실제 용례 | **개별 항목 이름으로 채택** |
| 절목(節目) | 조선 행정의 시행 세칙 — 가장 고증에 정확 | **시스템(관리 창) 이름으로 채택** |

**확정**: 관리 창 이름은 **「절목」**, 개별 항목은 **「~령(令)」** (절미령, 금주령, 방화령…).
낯선 말이지만 창 안에서 곧 "시행 세칙 묶음"임이 드러나고, 고증 정확도를 택한다.
첨사가 영을 내려 방(榜)을 붙인다는 연출("관아 앞에 방이 붙었습니다" 로그)로 반포를 표현.
향약은 훗날 부(府) 단계의 문화·자치 확장(4.3)으로 남겨 둔다.

## 2. 핵심 규칙

### 2.1 반포 창구와 슬롯

- **마을 중심지** 선택 → "절목" 행동으로 관리 창 진입 (중심지의 존재 이유 강화).
- 동시 시행 가능한 령 수는 승격 단계로 제한: 정착지 1 → 보 2 → 진 3 → 부 4.
  - **관청 + 아전**이 있으면 +1 슬롯. `officeEfficiencyMultiplier`(buildings.ts:449)처럼
    아전의 실무 능력이 행정력이 된다는 기존 문법과 일치.
- 각 령은 기본 3단계(강화/평시/완화) 또는 온오프. "평시"는 슬롯을 차지하지 않는다.

### 2.2 조령모개(朝令暮改) 방지

토글 남용(이주민을 받고 바로 모민령을 거두거나, 공사 중에만 부역령을 켜는 행동)을 막는 장치:

- 반포한 령은 **최소 한 계절(= seasonDays) 유지**해야 해제·변경 가능.
- 유지 기간 내 강제 변경은 허용하되 **"조령모개" 사기 페널티**(MoraleFactor로 노출)와
  명성 소폭 하락. "아침에 내린 영을 저녁에 바꾼다"는 문구 그대로 — 시대어가 곧 게임 용어가 된다.
- 아전이 있으면 최소 유지 기간 단축(행정력).

### 2.3 투명성

각 령의 효과·부작용은 조정 탭 의심 내역, 민심 내역과 같은 문법(`MoraleFactor[]`)으로
항목화해 노출한다. "절미령: 식량 소모 -25%, 민심 -6, 12일째 시행 중" 식.

#### 모민령 경계

- 지방 수령이 주민의 혼인 시기를 직접 조절하는 안은 폐기한다. 인구 조절은 **유민을 널리
  받거나 엄히 가리는 응접 정책**으로만 다룬다.
- 절목이 바꾸는 것은 무작위 일반 유민과 귀순민 제안이다. 플레이어가 외교로 직접 성사시킨
  이주, 조정 하사품, 통제 튜토리얼 이주는 영향받지 않는다.
- 제안을 거절해 이득만 보는 운용을 막기 위해 적극 모민 중 거절의 명성 손실, 수용 시 정착
  물자 부담 등은 구현 실측에서 확정한다.

#### 야금령과 가내수공업

- 현재 가내수공업은 귀가 뒤 짚신 삼기부터 시작한다. 야금령은 생산 배율 버튼이 아니라
  **저녁 마실을 금해 귀가 인구가 늘어난 결과**로 생산량이 증가해야 한다.
- 짚신 재고 목표만 채우면 효과가 사라지므로, 후속으로 새끼줄·멍석·바구니 등 가내수공업품을
  추가할 수 있는 공통 제작 목록을 둔다. 신규 품목의 실제 자원 편입은 별도 범위다.

#### 부역 대상과 저녁 행동 우선순위

- 첫 구현은 자유 직종 선택 UI를 두지 않고 **건축가·운반꾼을 토목 부역 대상으로 고정**한다.
  농부·어부·전문 장인까지 전 주민을 연장근무시키지 않는다.
- 연장 범위는 저녁 초반 4~6서브틱을 초안으로 한다. 건축가는 건설·보수·성벽 수리를,
  운반꾼은 공사 자재와 생산시설 보급을 계속한다. 밤까지 일하지는 않는다.
- 소년·환자·격리자·산후 조리 중인 주민은 연장 부역에서 제외한다. 평시 노인은 낮과 같은 기준으로
  참여할 수 있지만, 휼로령 시행 중에는 60세 이상을 명시적으로 면제한다.
- 야금령과 동시 시행할 때의 우선순위는 **긴급 행동(화재·재난·어선 귀환) → 토목 부역 대상의
  연장근무 → 나머지 주민의 귀가·가내수공업 → 평시 마실/귀가**다. 따라서 두 령은 서로의
  대상 인구를 나누며 직접 충돌하지 않는다.
- 후속 확장이 필요하면 개별 직종 다중 선택 대신 `토목(건축가·운반꾼)`·`산역(벌목꾼·채광꾼)`
  같은 단일 대상 유형을 둔다. 대상 유형 변경도 절목 변경으로 보아 유지 기간과 조령모개를
  적용한다.

### 후속·비범위 후보

| 령 | 전제 | 효과 | 대가 |
|---|---|---|---|
| **금주령**(禁酒令) | 술·주막 | 양조 중단 → 곡물 절약. 조정이 검약을 가상히 여김(의심 소폭 완화) | 주막 사기 효과 상실, 밀주 적발 사건 발생 확률 |
| **제수 규례** | 명절 달력 | 명절 잔치 기본 규모 설정 (성대히/평시/검소) | 성대히: 비축 부담 / 검소: 명절 사기 보상 감소 |

- **방역령은 상시 절목에서 제외**한다. 역병 발생 시 환자·동거인을 격리할지 결정하는 사건
  선택지로 유지한다.
- **출어 관련 절목은 제외**한다. 현재 어선은 풍랑 예보일에 신규 출항을 자동 취소하므로 별도
  금항 정책이 같은 결정을 중복한다.
- **혼인 장려·만혼령은 폐기**한다. 지방 수령의 시행 세칙으로 개인 혼인을 직접 조절하는 대신
  모민령이 인구 조절 역할을 맡는다.

### 3차 — 구역 지정형 (구현 비용 높음, 별도 계획 권장)

- **봉산령**(封山令): 지정한 숲의 벌목 금지 → 숲 재생 가속, 사냥감·약초 증가, 목재 수급 감소.
  실제 조선의 봉산 제도. 숲 재생(`map-forest-regrowth`)이 이미 있어 효과 계층은 준비됨.
  타일 구역 지정 UI가 필요해 별도 스코프.

## 4. 다른 축과의 상호작용

### 4.1 조정(朝廷)

가볍게 1~2개만 연결한다 (과하면 의심 시스템과 중복):

- 금주령 시행 중 → 감찰 시 "검약" 긍정 평가 (의심 소폭 완화)
- 기근 중 "후히 배급" → 감찰 시 "창고를 헐어 민심을 샀다"는 트집 가능성 (모반 의심 문법 재사용)

### 4.2 위기 대응 루프

이 시스템의 존재 이유는 **위기 때 플레이어에게 능동적 결정권**을 주는 것.
현재는 흉년이 오면 지켜볼 수밖에 없지만, 절목이 있으면
"절미령+절탄령으로 버티되 민심·건강 출혈을 감수한다"는 조선식 위기 경영이 된다.
대기근의 해(콘텐츠 제안 2.3) 아크와 결합하면 프로스트펑크식 긴장을 조선 문법으로 재현.

### 4.3 향약 (후반 확장 여지)

부(府) 승격 후 문해율·서당·유배 선비와 연계해 「향약 반포」를 별도 마일스톤으로:
민심 자정(경조사 상호부조, 치안 소사건 감소) 같은 자치 효과.
절목(관 주도)과 향약(민간 자치)의 대비 자체가 콘텐츠가 된다. 본 설계에선 범위 밖.

## 5. 구현 스케치

```ts
// types.ts
export type EdictId = 'ration' | 'fuelRation' | 'immigration' | 'fireCode' | 'curfew' | 'elderCare' | 'corvee' | ...;
export type EdictLevel = 'tight' | 'normal' | 'generous'; // 령마다 유효 단계 상이

interface EdictState {
  level: EdictLevel;
  sinceDay: number;        // 조령모개 판정·"n일째 시행" 표기
  target?: 'civilWorks' | 'mountainWork'; // 부역 대상형 확장 시 사용. 1차는 civilWorks 고정
}
// GameState에 edicts?: Partial<Record<EdictId, EdictState>> 추가 (구버전 저장 = 전부 평시)
```

- `config.ts`에 `CONFIG.edicts`: 단계별 배율, 최소 유지 일수, 민심 델타.
- 각 시스템의 일일 틱에서 배율·행동 분기를 조회한다. 모민령은 무작위 이주 제안, 방화령은
  발화·확산, 휼로령은 노년 효율·노환, 야금령·부역령은 저녁 행동 스케줄에 연결한다.
- 민심: `moraleBreakdown`에 시행 중인 령의 팩터 추가.
- UI: 중심지 선택 행동 + 관리 창 1개 (기존 관리 창 문법). 반포/변경 시 방(榜) 로그.
- 저장: `saveSchema` 마이그레이션 — `edicts` 부재 시 빈 객체.
- 테스트: `tools/game/test_edicts.mjs` — 배율 적용, 슬롯 상한, 최소 유지 기간, 조령모개 페널티.

## 6. 착수 순서

1. 골격 + **절미령·절탄령** (배율 2개, 위기 대응 가치 즉시 체감) — **2026-07-25 완료 (§8)**
2. **모민령·휼로령** — 기존 확률·배율 훅을 우선 연결
3. **방화령** — 이미 구현된 화재 발화·확산과 화기 작업장 생산을 함께 조정
4. **야금령 + 가내수공업 공통 골격** — 짚신부터 시작하고 품목 확장 자리를 마련
5. **토목 부역령** — 건축가·운반꾼 저녁 연장근무와 야금령 우선순위까지 통합
6. 술·명절 실장 뒤 **금주령·제수 규례**, 별도 구역 계획으로 **봉산령** 검토

## 7. 밸런스 원칙

- 모든 령은 **항상 켜두면 손해**여야 한다. 대가 없는 령은 슬롯·조령모개가 아니라
  효과 설계 단계에서 걸러낸다 (절미령의 대가는 민심이 아니라 누적 건강 저하가 본체).
- 슬롯 제한은 "무엇을 포기할 것인가"를 만드는 장치 — 부(府)에서도 전부 켤 수는 없게.
- 기본값(평시)은 현재 게임과 동일 거동. 절목을 한 번도 안 열어도 지금과 같은 게임이어야 한다.

## 8. 구현 현황 (완료 — 2026-08-05)

금주령·제수 규례·봉산령은 전제 콘텐츠 또는 별도 구역 계획이 필요한 명시적 후속 범위다.

구현 중 굳힌 규칙:

- **대가는 배율이 아니라 충족률에서 나온다.** 소비량만 줄이고 배부름·체온 충족률을 평시 몫으로
  재기 때문에, 절미령은 "끼니를 거른 이"를, 절탄령은 "식은 아궁이"를 만든다. 배급으로 아낀 것은
  부족 경고 로그로 뜨지 않는다 (의도한 절약과 진짜 결핍을 구분).
- 절탄령의 혹한·눈보라 가중은 `harshWeatherMult`로 명시. 날씨로 커진 수요에 비율 배급이 걸리므로
  절대 부족량도 함께 커진다 — 눈보라 속 절탄령은 실제로 위험하다.
- 이미 시행 중인 령의 **단계 변경은 슬롯을 새로 쓰지 않는다** (절미 → 후히는 여전히 1슬롯).
- 첫 반포는 조령모개가 아니다. 유지 기간 판정은 "직전 변경일"만 본다.
- 모민령은 무작위 제안에만 적용하고 외교·조정·튜토리얼의 직접 이주는 건드리지 않는다.
- 방화령은 발화 0.55배·확산 0.7배와 화기 직종 생산 0.9배를 한 묶음으로 적용한다.
- 야금령은 저녁 마실을 귀가로 바꾸고, 늘어난 재택 시간을 짚신 산출 1.5배와 인구 비례 비축 목표로
  반영한다. 실제 제작은 `householdCraft.ts` 목록을 통해 후속 품목을 추가할 수 있다.
- 휼로령은 60세 이상 노동효율을 평시 0.85에서 0.60으로 낮추는 대신 노환 0.5배·일상 질병
  0.65배와 토목 부역 면제를 준다.
- 토목 부역은 건축가·운반꾼에게만 저녁 첫 5서브틱을 연장하고 매 틱 건강 0.04를 소모한다.
  화재·전투·어선 행동과 폭설 대피는 이 분기보다 앞선다.
