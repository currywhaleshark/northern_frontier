# Modular Wall Sprite Implementation Plan

> **For agentic workers:** The previous 16-mask/bitmask wall-family route is retired. Do not regenerate or extend the 16-mask sheets unless the user explicitly asks to return to that approach.

**Goal:** Ship a compact three-piece modular wall sprite system for normal wall rendering: `pillar`, `horizontal`, and `vertical` per material and season.

**Architecture:** Keep gameplay connection detection in `src/game/walls.ts`. Keep render-only modular asset metadata in `src/render/wallFamilyAssets.ts`. Gates remain gameplay wall-family connectors, but base wall art excludes gates until a separate gate asset path is designed.

---

## File Structure

- Modify: `src/render/wallFamilyAssets.ts`
  - Owns modular sheet metadata, wall material mapping, piece classification, and source rect lookup.
- Modify: `tools/render/test_wall_family_assets.mjs`
  - Tests modular piece classification and type narrowing.
- Modify: `tools/render/compose_wall_family_assets_v1.py`
  - Composes six three-cell source rows into one modular sheet.
- Modify: `tools/render/test_wall_family_asset_pixels.py`
  - Tests modular compose dimensions, key removal, alignment, and validation errors.
- Modify: `docs/superpowers/specs/2026-07-08-wall-family-sprite-generation-design.md`
  - Documents the modular design.
- Add later: `tools/render/source_images/wall-family-*.png`
  - Three-cell source sheets in `pillar`, `horizontal`, `vertical` order.
- Add later: `public/assets/wall-family-modular-v1.png`
  - Shipped modular wall sprite sheet.
- Add later: `docs/assets/walls/wall-family-modular-v1-preview-4x.png`
  - QA preview generated by the compose script.
