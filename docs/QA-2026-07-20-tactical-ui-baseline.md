# 전술 UI 기준선 — Phase 3 개편 전 스크린샷·상호작용 목록

> 작성: 2026-07-20 (Fable) · 전투확장 2단계 Phase 0의 프론트 몫
> 캡처 시점: 통합 7935631 + 프론트 4534c5e (Phase 2 프론트까지 반영)
> Phase 1·2는 정보 표시만 바꿨으므로, 이 기준선은 Phase 3(빈 전장 배치·카드 독)과
> Phase 4(무대 드래그)가 갈아엎을 **배치·지휘 조작 방식**의 "이전 모습" 기록으로 유효하다.

스크린샷: [`docs/qa/tactical-baseline-2026-07-20/`](qa/tactical-baseline-2026-07-20/) —
방어전 6장면 + 사냥 배치 1장면 × 1280×720 / 1920×1080, 총 16장.
캡처 조건: 홀라온 야인 · 경보됨 · 겨울 (사냥은 늑대 사냥 기본값). 재현 스크립트는 Playwright 기반이며
시뮬레이터 → 준비 2건 선택 → 실행 → 배치 → 지휘 → 교전 1회 순서로 진행했다.

## 장면 목록

| 파일 | 장면 |

| `sim-setup-*` | 전투 시뮬레이션 설정 (교리·편제·우회 강제 옵션 포함) |
| `defense-preparation-*` | 준비 단계 — 준비태세 카드 그리드 + 적 정보 패널 |

| `defense-command-*` | 지휘 단계 — 부대 독 + 적 정보 패널(교리·편제·행동 징후) |
| `defense-command-popover-*` | 부대 선택 시 명령 팝오버 |

| `defense-round-report-*` | 라운드 보고 |

## 현행 상호작용 목록 (2026-07-20 기준)

### 준비 단계 (preparation)

- 준비태세 카드 클릭 = 선택 토글. 비용은 준비점수에서 차감 예약, 실행 전까지 재클릭으로 취소.
- 공개된 적 계책을 카운터하는 카드에는 대응 태그가 붙는다 (`enemyPlanCounterLabelsForAction`).
- `선택한 준비 실행` → 준비 연출 재생(preparationExecution) 후 배치 단계로 자동 진행.
- 적 정보 패널: 한 줄 요약 + 목적/교리/편제/계책 4블록 + 공개 부대 행동 징후.

### 배치 단계 (deployment) — **Phase 3에서 사라질 방식**

- 전투 생성 시점부터 모든 부대가 기본 구역·열에 **이미 배치되어 무대에 보인다** (빈 전장 아님).
- 하단 독: 부대 칩(스프라이트·인원·현재 구역·열) 클릭으로 선택.
- 선택 부대 아래에 **구역 버튼 4개**(접근로/마을 방어선/창고 주변/마을 중심지) + **열 버튼 3개**
  (전열/중열/후열)가 나타나고, 클릭 즉시 이동 적용. 확인 단계 없음.
- 피난 주민은 이동 불가(잠김), 치료반은 구역만 선택 가능.
- 사냥 전투 한정: 분견대 `나누기`(1명 단위 지정) / 같은 원대 조각 `합치기` 버튼 —
  Phase 3에서 일반 전투로 공통화될 원본 (`splitHuntGroup`/`mergeHuntGroups`).
- 민병 소집을 준비에서 실행했으면 이 시점에 이미 방책 전열에 스프라이트로 서 있다
  (Phase 3에서 카드 대기 방식으로 변경 예정).
- `전투 시작` → 지휘 단계.

### 지휘 단계 (command)

- 부대 선택 경로 3개: 하단 독 칩 클릭 / 무대 스프라이트 클릭 / 미니맵 부대 점 클릭.
- 선택 시 명령 팝오버(빠른 액션 스트립): 지원 명령 버튼들 + 열 이동 + 인접 구역 이동 + 명령판 열기.
- 명령판(전체 보드): 부대별 명령·설명·불가 사유 일괄 표시.
- 집중 표적: 사거리 안 적 그룹 클릭으로 지정/해제. 사거리 밖 그룹은 비활성 스타일.
- 후방 급습 발생 시 후방 대응 선택지(`reinforceRear`/재배치/사격 전환/무대응)가 별도 노출.
- 명령 미지정 부대로 선택이 자동 순환(클릭 수 절감). Escape = 팝오버 닫기.
- 무대 이동: ‹ › 구역 네비 버튼, 미니맵 구역 노드 클릭. 무대 자체는 scroll-snap 가로 스크롤.
- `교전 개시` → 재생.

### 재생·보고 (simulating / report)

- 재생 중 무대 클릭 또는 스페이스 = 배속(fast-playback). 결과(outcome) 이벤트는 항상 표시.
- 자막 타자기 효과, 진영별 플로팅 전황 텍스트, 이벤트별 효과음·연출 클래스(`event-*`).
- 라운드 보고 패널 → `보고 확인` → 다음 라운드 지휘 또는 종료.
- 종료 시 장계 모달(`TacticalBattleReportModal`): 등급·사상·노획·관계 변화.

### 키보드·접근성 현황

- 모든 조작이 버튼 기반이라 Tab 순회 + Enter로 동등 수행 가능 (Phase 4 드래그 도입 후에도
  이 경로를 유지하는 것이 [확정] 조건).
- 스크롤 컨테이너의 sticky 헤딩과 `scroll-margin-top`으로 포커스 가림 방지.
- `prefers-reduced-motion` 대응은 현재 눈·연출 일부에만 적용 — Phase 4에서 고스트 애니메이션에
  확대 예정.

## Phase 3/4 회귀 비교 시 주의점

- `defense-deployment-*`의 "이미 배치된 무대"가 빈 전장 + 카드 대기로 바뀌는 것이 핵심 변화다.
  자동배치 결과는 이 스크린샷의 구역·열과 완전히 같아야 한다(계획서 확정 조건).
- 독 칩의 구역·열 버튼 방식은 Phase 4에서 드래그+확인 카드로 대체되되 접근성 폴백으로 남는다.
- `hunt-deployment-*`의 나누기/합치기 UI가 일반 전투로 확장되면 이 장면과 동작 비교가 기준이 된다.
