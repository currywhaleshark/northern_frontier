## 상태 구조

- `militaryAid`: 사절이 돌아온 뒤 특정 산채 원정에 합류를 기다리는 외부 전사
- `Expedition.externalAid`: 원정 생성 순간 소비된 원병 편제와 누적 사상자
- `warDispatch`: 부족 전쟁에 파견된 주민 ID와 요청·상대 세력, 귀환일
- `lastWarParticipationOfferYear`: 연차별 참전 요청 중복 방지

외부 원병 전술조는 `residentIds: []`를 유지한다. 전술조의 `count/killed/wounded`를
`Expedition.externalAid`에 별도로 결산하므로 외부 전투원이 저장 주민으로 남거나
`killResidents`의 주민 후보가 되는 일이 없다.
