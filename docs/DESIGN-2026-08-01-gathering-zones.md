# 채집 영역 체제 설계 — 작업영역·서식지 자원화·숙식 움막

> **계획 상태:** 미착수 (2026-08-01 사용자 구술 확정 — 구현계획 미작성)
> **상태 갱신:** 2026-08-01 — 설계 확정. [방어 개편](DESIGN-2026-08-01-defense-overhaul.md)보다 **먼저 착수한다** (사용자 지시).

- 작성일: 2026-08-01 (사용자 구술 + Fable 검토·코드 대조)
- 관련 설계: [방어 개편](DESIGN-2026-08-01-defense-overhaul.md) — 숲 벨트 유지(벌목 통제)라는 지점에서 만나는 별도 트랙. 독립 착수 가능.

## 0. 문제 진단

1. 채집(벌목·사냥·약초·채광)이 전 맵 자유 방랑이라 **플레이어가 숲을 남길 수단이 없다** — 방벽림·경관·서식지 유지가 전부 운에 달렸다.
2. 채집 건물(벌목장·사냥막·약초막)이 하역처에 그쳐 **위치의 전략적 의미가 얕다.**
3. 사냥감·광물의 소진이 위치 선택으로 이어지지 않는다 — 옮겨 다닐 이유가 없다.
4. 채집 동선이 길어지면 하루 사이클(귀가·취침) 때문에 **밤늦게 돌아와 금방 나가는** 부자연스러운 왕복이 생긴다.

## 1. 확정 방향 (2026-08-01)

1. **작업영역 지정**: 벌목장·사냥막·약초막·채광장이 채광장의 반경 작업 모델(`mineWorkRadius`)처럼 **지정된 영역 안에서만** 채집한다. 영역은 건물을 선택해 위치·크기를 조절할 수 있다.
2. **배치 필수화**: 채집 직업은 해당 건물에 배정되어야 일한다 — 자유 방랑 채집 제거. 이에 따라 **채광장을 1티어(촌)로 내린다.**
   - 주의: R5에서 확정한 "노두 자유 채집 + 채광장 보 전용"을 **의도적으로 뒤집는** 결정이다. 당시엔 건물 없이 캐는 세계관에서 맞는 선택이었고, 새 체제에서는 채광장이 1티어 앵커가 된다. 노두 고정 배치(마을 옆 돌·철)는 그대로 유효 — 이제 "1티어 채광장의 첫 영역"이 된다.
3. **서식지 자원화**: 사냥터(서식지)에 천천히 회복되는 저장량을 둔다. 소진되면 옮겨 다니며 사냥하고, **주변 숲이 남아 있으면** 시간이 지나 회복된다. 벌목 통제(1)와 맞물려 "숲을 남기는 플레이"에 실질 보상이 생긴다.
4. **숙식 움막(임시 막)**: 작업장과 링크된 저렴한 움막을 지으면, 작업자가 마을에서 **식량·땔감을 가져가 움막에 두고 숙식하며** 일한다. 비축이 다하면 집으로 돌아가 하루 쉬고, 다음 날 다시 보급을 지고 나간다. 원거리 영역의 왕복 낭비(문제 4)를 해소하는 짝 메커니즘 — 영역 체제가 만든 원거리 작업지는 움막 없이는 비효율, 움막은 영역 없이는 무의미.

## 2. 단계 구성

| 단계 | 내용 | 비고 |
|---|---|---|
| G1 | **벌목장 작업영역** — 반경/사각 영역, 선택 UI로 위치·크기 조절, 벌목꾼은 배정 벌목장 영역만 벌목 | 채광장 모델 이식. 숲 보존의 첫 수단 |
| G2 | **사냥막·약초막 확장 + 서식지 자원화** — 영역 이식, 서식지 저장량·회복(숲 잔존 조건), 남은 짐승을 읽는 UI(사냥막 선택 정보) | 정보 없이는 불합리한 벌칙처럼 느껴진다 — UI 필수 |
| G3 | **배치 필수화 + 채광장 1티어** — 자유 방랑 제거, 시작 흐름·저장 마이그레이션·튜토리얼 연쇄 수정 | 가장 파급이 큰 스위치. §4 참조 |
| G4 | **숙식 움막** — 작업장 링크, 보급(식량·땔감) 적재·소모, 현지 취침, 소진 시 귀가·재보급 루프 | 하루 사이클 위상(rest/sleeping)에 현지 취침 추가 |

## 3. 기존 시스템 접점 (2026-08-01 코드 대조)

| 신규 요소 | 재사용할 기존 문법 |
|---|---|
| 반경 작업영역 | 채광장 `mineWorkRadius` + `mineralDepositsInMineRange` |
| 영역 크기 조절 | 밭 드래그 크기 지정 (2026-07-17) — 사각형이면 그대로, 반경이면 선택 창 슬라이더 |
| 건물 배정 | 작업자 슬롯 (`buildingWorkerSlots`), `assignedBuildingForResident` |
| 채집 목표 탐색 | `gatherJob`/goal field — "전 맵 → 영역"으로 좁히는 구조 변경 (성능은 오히려 유리) |
| 서식지 | `habitats` (id·위치·반경·active) — 저장량·회복률 필드 추가 |
| 숲 재생 | `forestGrowth` — 서식지 회복의 "숲 잔존" 판정에 재사용 |
| 움막 취침 | 하루 사이클 위상(rest/toHome/sleeping) — 취침지를 집 대신 움막으로 |
| 움막 보급 | 건물 재고(`addBuildingStock`) + 운반 문법. 첫 판은 작업자 본인이 지고 간다(운반꾼 개입 없음 — 사용자 구술 그대로) |
| 겨울 난방 | 움막 체류 중 땔감 소모 — 기존 난방 소모 문법 |

## 4. G3의 파급 — 반드시 함께 처리할 것

- **시작 흐름**: 현재 벌목꾼은 1일차부터 건물 없이 일한다. 배치 필수화 후에는 벌목장이 선행 — 시작 마찰을 줄일 장치가 필요하다(벌목장 건설비 인하, 또는 시작 벌목장 1채 제공 — 결정 항목 1).
- **튜토리얼 연쇄**: R1(1단계 벌목꾼 즉시 배정)·R5(광물 스텝 "채광꾼 배정만", 채광장 설명문, 노두 불변식)가 직접 영향권. G3와 같은 라운드에서 튜토리얼 후속 라운드로 수정하고 회귀 테스트를 갱신한다.
- **저장 마이그레이션**: 기존 저장의 방랑 채집꾼을 가까운 채집 건물에 자동 배정(없으면 무직 전환 + 안내 로그).
- **guides**: 채광장·서식지 관련 초회 도움말 문구 갱신.

## 5. 숙식 움막 세부 (사용자 구술 기준)

### 5-0. 선행 조건 논점 — 전역 소비 대 국지 소비 (2026-08-01 사용자 제기)

현행 소비는 전역이다: 식량·땔감이 마을 곳간(`resources`)에서 일괄 차감되고, 가구(집) 단위 비축은 어디에도 없다. "가져가서 숙식하다 떨어지면 귀가"가 성립하려면 소비의 국지화가 필요하다는 지적은 옳다. 두 길이 있다:

- **A안 (권고): 움막 국지 재고를 특례로 먼저.** 출근 적재 시 전역 곳간에서 차감해 움막 재고로 옮기고, 체류자의 일일 소비는 움막 재고에서만 나간다. 마을 쪽 소비는 전역 유지. 가구당 분배 없이 움막 루프가 완결되고, 침습 범위가 움막 하나로 갇힌다.
- **B안: 가구당 식량·땔감 분배를 먼저 실장.** 모든 집이 비축을 갖고 주민이 제 집 몫을 소비하는 전면 개편 — 온돌 난방의 현실화(집마다 장작), 배급 정책, "전역 냉장고" 제거라는 독립 가치가 크지만, 소비·물류·성능·밸런스 전반을 건드리는 별도 대형 설계다.

**권고는 A안이다.** 움막(G4)을 가구 분배에 종속시키면 QoL 수정 하나가 대형 개편 뒤로 밀린다. A안의 움막 국지 재고는 나중에 B안이 오면 "가구 비축의 한 사례"로 자연 흡수된다 — 특례가 빚이 되지 않는 방향으로 재고 모델(건물 재고 문법)을 쓴다. **가구당 분배 자체는 독립 설계 후보로 등재**하되(→ §7-6), 본 설계의 선행 조건으로 삼지 않는다.

- 링크: 움막은 채집 건물을 지정해 링크(또는 영역 안 배치 시 자동 링크). 1작업장 1움막부터 시작.
- 보급 루프: 출근 시 마을 곳간에서 n일분 식량·땔감을 지고 가 움막에 적재 → 체류하며 일·숙식(일일 소모) → 바닥나면 귀가 → 다음 날 재보급 후 복귀. "밤늦게 들어와 금방 나가는" 왕복이 "며칠 체류 + 하루 귀가"로 바뀐다.
- 균형·정서 장치(후속 결정 3): 체류 일수 상한 또는 체류 중 완만한 사기 저하(집·가족과 떨어짐) — 움막이 상시 이주가 되지 않게. 병자는 즉시 귀가.
- 위험 노출: 움막 체류자는 마을 밖에서 밤을 보낸다 — 맹수·습격 위협과의 상호작용은 방어 개편 트랙과 접점(후속 결정 4). 첫 판에서는 판정 없이 서사만.

## 6. 경계

- **영역 미지정/영역 내 자원 고갈**: 작업자가 멈추면 반드시 원인을 말해야 한다(기존 "대기 사유" 문법) — "영역에 벨 나무가 없습니다" 류.
- **서식지 고갈로 초보자 굶김**: 사냥은 두 번째 곳간 — 회복 기본값을 후하게, 저장량 UI(G2) 필수.
- **움막 만능화**: 보급 상한과 사기 장치로 "전원 움막 이주" 퇴화 방지.

## 7. 후속 결정 항목

1. G3 시작 마찰 해소 방식 — 벌목장 건설비 인하 vs 시작 제공
2. 영역 모양 — 반경(채광장 통일) vs 드래그 사각(밭 통일). 첫 판은 한 가지로 통일 권장
3. 움막 체류의 사기·일수 상한 수치
4. 움막 체류자의 야간 위험 판정 (방어 개편 P3 이후 재검토)
5. 어부(fisher)도 영역 체제에 편입할지 — 첫 판 제외
6. **가구당 식량·땔감 분배** (§5-0 B안) — 독립 설계 후보. 온돌 난방 현실화·배급 정책·전역 소비 제거와 묶이는 대형 개편. 움막 특례(A안)가 자리 잡은 뒤 별도 설계서로 검토
