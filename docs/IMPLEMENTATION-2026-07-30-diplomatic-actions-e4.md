# 외교 활동 E4 근접 경고 구현계획

> **계획 상태:** 완료
> **상태 갱신:** 2026-07-30 — P0~P3 구현과 E4 표적 회귀·E2 보존 회귀·프로덕션 빌드를 완료했다. v50 마이그레이션으로 구세이브를 빈 누적값에 연결한다.

- 원전 설계: [외교 활동 설계](DESIGN-2026-07-30-diplomatic-actions.md) §A4
- 범위: 생활권의 바깥 2칸 완충 감시, 같은 완충 칸의 반복 작업, 세력 거점 주변의
  주민·원정대 배회, 세력×사유 1회 경고와 이후의 약한 압박.
- 비범위: A5 생활권 협정의 구매·면제 선택지, A6 원병, 기존 생활권 내부 침해의
  배상 모달 규칙 변경.

## 구현 순서

- [x] P0 — 현재 `claimZones`·`territory`·외국 거점·사절 상태 경로를 점검하고
  완충/배회 상수와 저장 진행값을 정한다.
- [x] P1 — 완충 안 건물 완공과 같은 칸 반복 작업을 감지하고 지도자 명의 1회 경고를 남긴다.
- [x] P2 — 외국 거점 주변 배회와 경고 후 지속 압박(관계·경계심/위협)을 일일 틱에 잇는다.
- [x] P3 — 중요 로그를 중앙 액션 알림으로 전달하고, 저장 정규화·표적 회귀·프로덕션 빌드를 검증한다.

## 판정 규칙

- 생활권 내부의 기존 침해는 그대로 `claimZones`/`territory`가 처리한다. E4는 각
  생활권 경계 **바깥** 2칸만 본다.
- 반복 작업은 같은 완충 칸에서 3일 누적 시 경고한다. 거점 배회는 거점 외곽 3칸에서
  3일 연속 체류 시 경고한다.
- 경고 키는 `세력×사유(claimBuffer | siteLoiter)`로 한 번만 쓴다. 해당 행동이
  계속될 때만 4일 간격으로 기존 침해보다 약한 압박을 더한다.
- v50 마이그레이션은 기존 v49 저장의 누적 진행값을 빈 객체로 넣는다. 경고 dedupe
  배열은 v49의 `proximityWarnings`를 그대로 보존한다.
