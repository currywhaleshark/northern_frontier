# 재난 일러스트와 수리 시설 아트 구현계획

> **계획 상태:** 완료
> **상태 갱신:** 2026-07-29 — 사건 카드 3종을 깨끗한 수묵담채 3:1 일러스트로 교정하고 준탑뷰 보·제방 자산과 제방 변 배치 검증을 마쳤다.

## 목표

- 새 재난 선택 카드에 사건을 한눈에 읽을 수 있는 깨끗한 수묵담채 일러스트를 붙인다.
- 임시로 다리·성벽 칸을 공유하던 보와 제방을 독립 지도 스프라이트로 교체한다.
- 일반 및 최대 줌(HD) 모두에서 선명하게 보이며, 투명 가장자리에 마젠타 잔색이 남지 않게 한다.

사건 삽화의 이후 제작·재작업은 [사건 삽화 아트 스타일 기준](ART-STYLE-EVENT-ILLUSTRATIONS.md)을 따른다.

## 확정 범위

- [x] 늦서리, 황충 떼, 가축역병 사건 카드를 표면 노이즈를 억제한 수묵담채 3:1 일러스트로 제작·연결
- [x] 지형 바탕이 섞이지 않은 준탑뷰 보·제방 가로/세로 4셀 표준(28×28) 및 HD(56×56) 시트 제작·연결
- [x] 제방을 강 타일의 육지 쪽 변에 붙이는 비점유 오버레이로 연결
- [x] 인접 논밭 보존, 일반 강가 건물 공존, 방앗간·나루터·부두 겹침 금지
- [x] 마젠타 크로마키 알파 정리와 시트 시각 확인
- [x] 표적 빌드 및 자산 참조 회귀 확인

## 비범위

- 가뭄·대홍수·설해는 현재 선택 카드가 아닌 지도·경보 연출만 있으므로, 별도 사건 카드 UI를 만들지 않는다.

- 2026-07-29: 기존 `specialEvents.ts`와 건물 아틀라스를 점검했다. 선택 카드가 없는 가뭄·대홍수·설해는 지도 연출 범위로 유지한다.
- 2026-07-29: `late-frost-v1`, `locust-swarm-v1`, `livestock-epidemic-v1` 사건 일러스트와 `waterworks-buildings` 표준/HD 시트를 추가했다. `npm run build`, `test_livestock_epidemic.mjs`, `test_disaster_climate.mjs`를 통과했고, 두 시트의 가시 마젠타 픽셀 0개를 확인했다.
- 2026-07-29: 보·제방을 게임 시점에 맞춘 가로/세로 4셀 `v2` 시트로 교체했다. 제방은 클릭한 강 타일 변을 따라 그려지며 강 칸을 점유하지 않고, 해당 변을 건너는 대홍수 유입만 차단한다. `test_spring_flood_weir_reservoir`, `test_selection_actions`, `test_pending_disasters`와 프로덕션 빌드를 통과했다.
- 2026-07-29: 도트풍이던 사건 카드 3종을 기존 사건 카드 계열에 맞는 수묵담채로 다시 생성했다. 종이결·점묘·석판화식 잔선을 억제하고 UI 표시 비율과 같은 2172×724(3:1)로 교체했다.
