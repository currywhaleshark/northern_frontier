# 외교 인물 — 부족 지도자와 북병사 (설계)

> **계획 상태:** 일부 완료
> **상태 갱신:** 2026-07-30 — F1 인물·임기, F2 북병사 성향 보정, F3 대표 명의/UI와
> 잔여 사건 문구 감사를 구현·검증했다. F4 초상 16종만 후속이다.

- 작성: 2026-07-30
- 동기: 외교·조정 상호작용이 전부 집단("오도리 씨족이", "조정이") 명의라 얼굴이
  없다. 인물을 세우면 몰입이 오르고, 무엇보다 **후반 엔딩의 패자(覇者)가 인물이어야
  한다** — 통일하는 것은 부족이 아니라 몇 년을 알고 지낸 이름이다. 역사 시계가
  돌기 전에 그 이름들을 미리 심는다.

## 0. 원칙

1. **인물은 세력의 얼굴이지, 새 외교 시스템이 아니다.** 우호도·의심·세공 같은
   수치 체계는 지금처럼 세력/조정 단위를 유지한다. 인물별 게이지를 만들지 않는다.
2. **비대칭 설계.** 부족 지도자는 오래가므로 성향이 수치에 닿지 않는다(연출 전용).
   북병사는 임기마다 갈리므로 성향이 실효 보정을 갖는다 — 교체가 곧 변주다.
3. **결정적 생성.** 이름·성향은 시드(+세력 id / 임기 번호)의 순수 함수다.
   저장을 되감아도 같은 인물이 온다. 엔딩 계획 §0-1(난수 금지)과 정합.
4. 부임·계승은 연대기(court/special)와 소문 비트에 기록된다 — 연대기 시스템 재사용.

## 1. 부족 지도자 (연출 전용)

- 세력마다 1인: **이름 + 칭호 + 성향 1개**. 성향은 대사·문체 선택에만 쓴다.
- 이름 풀: 조선왕조실록에 오도리·올량합·골간·니마차·홀라온 인물로 실제 기록된
  음차명을 집단별로 분리해 쓴다. 왕조 시조급·정치적으로 유명한 실존 인물은 제외한다.
  근거와 풀은 [F1+F3 구현계획](IMPLEMENTATION-2026-07-30-diplomatic-figures.md)에
  고정한다. 칭호는 세력 규모에 따라 족장/추장.
- 안정된 부족 대표를 두는 대상은 오도리 씨족·올량합 부락·골간 우디캐·니마차
  우디캐·홀라온 야인 5세력이다. 만상·송상은 조선 상단이고 변경 마적은 혼성 무장
  집단이므로 부족 지도자 생성 대상에서 제외한다.
- 등장 지점 (전부 기존 문구에 명의를 얹는 방식):
  - 교역 협상 창: "○○ 족장이 보낸 사절" — 성향별 인사말 1줄
  - 최후통첩·공물 요구: "○○ 족장이 공물을 요구하며…"
  - 습격 결산문: 세력명 자리에 "○○ 족장의 무리"
  - 세력 창(FactionsWindow): 세력 줄에 지도자 이름·칭호 표시
- **교체 없음(v1).** 사망·계승은 역사 시계 1막의 사건이다 — 그때 "어느 세력의 젊은
  새 지도자가 유난히 강성하다"는 교체가 통일 서사의 시작이 된다. 여기서는 자리만
  만들고 건드리지 않는다.
- 후반 연결: 패자 선정(엔딩 계획 §2) 시 그 세력 지도자 이름이 칸호(汗號)를 얻는다.

## 2. 북병사 (임기제 · 실효 성향)

조정 상호작용의 얼굴. 왕은 멀리 있고, 육진의 직속 상관인
**함경북도 병마절도사(북병사)** 가 모든 조정 문서의 명의가 된다.

### 2-1. 임기

- **임기 2년(96일), 고정 주기 체차.** 역사상 북병사 임기도 2년이다. 세공이 격년이라
  "한 북병사와 세공 한 번"의 리듬이 생긴다.
- 임기 경계는 결정적: `임기 번호 = floor((day - 1) / (yearDays * 2))`. 부임일에
  소문 비트("새 북병사 ○○○ 부임 — 송사에 엄한 자라더라") + 연대기 `court` 1건.
- 이름·성향은 `hash(seed, 임기 번호)`의 순수 함수. 조선식 성명(성+2자) 풀.
- 조기 교체(견책·토벌 사건 연동)는 후속 옵션 — v1은 고정 주기만.

### 2-2. 성향과 실효 보정 (초안 — 구현 시 수치 조정)

성향 4종, 성향당 보정 2개. 전부 **기존 다이얼에 곱하는 소폭 보정**이며 새 시스템을
만들지 않는다. 수치는 UI에 노출하지 않고 부임 소문과 조정 창 한 줄 설명으로 암시한다.

| 성향 | 소문 문구(예) | 보정 1 | 보정 2 |
|---|---|---|---|
| **엄격** | "송사에 엄하다더라" | 의심 상승 +15% (감찰 잦음) | 세공 성실 시 하사 물목 +1단계 후함 |
| **탐욕** | "손이 크다는 소문이 곱지 않다" | 청원 명성 비용 +25% | 하사 물목 박함 (기물 확률은 불변) |
| **온건** | "변방 사정에 너그럽다더라" | 의심 자연 감소 +25% | 세공 불이행 유예 1회 관대 |
| **지장** | "국경 지리에 밝은 무관이라더라" | 청원 물자 +25% | 위협도 자연 감소 소폭 가속 |

- 보정이 닿는 다이얼: 의심(suspicion) 증감률, 하사 물목 등급, 청원 비용/산출,
  세공 불이행 판정, 위협도 감쇠. **우호도·교역가에는 닿지 않는다** — 그쪽은 세력
  지도자의 영역이 아니라 세력 자체의 수치다.
- 후반 엔딩과의 정합: 근왕 조건 축(조정 관계 = 세공 성실·하사 이력)의 **누적 자체는
  흔들지 않는다**. 성향은 그 해의 손익을 소폭 바꿀 뿐, 조건 도달 가능성을 막지 않는다
  (§0-3 결정적 생성이므로 "운 나쁜 북병사 연속"도 시드에 결정돼 있고, 보정 폭이
  작아 어느 시드든 조건 도달이 가능해야 한다 — 수치 확정 시 이 기준으로 검증).

### 2-3. 명의가 실리는 곳

세공 사자 도착·결산 문구, 하사 교지("북병사 ○○○이 전한다"), 견책·감찰 파견,
개칭 허가, (후반) 근왕 교지. 기존 문장의 주어를 바꾸는 수준 — 문구 전면 개편 아님.

## 3. UI

- **조정 창(CourtWindow)**: 상단에 북병사 카드 — 초상·이름·성향 한 줄 설명·임기
  잔여("체차까지 ○일"). 수치 보정은 표기하지 않는다.
- **세력 창(FactionsWindow)**: 세력 줄에 소형 초상 + 지도자 이름·칭호.
- **협상 창(TradeDialog)**: 상대 세력 지도자의 초상과 인사말 1줄을 상단에 표시.
- 사건 카드(최후통첩·감찰 등)는 기존 일러스트 체계를 유지한다 — 초상을 카드에
  끼워 넣지 않는다.

### 3-1. 초상 (생성 파이프라인 사용)

- 기존 사건 카드와 같은 **수묵담채 초상**을 생성 파이프라인(tools/render 관례)으로
  만든다. 개인별 생성이 아니라 **성향별 풀**을 만들어 돌려쓴다:
  - 조선 북병사: 성향 4종 × 2변형 = 8종 (관복·무관 차림)
  - 여진 지도자: 성향 4종 × 2변형 = 8종 (성향 4종은 연출용 — 호방/노회/과묵/사나움)
- 배정은 결정적: `hash(인물 이름) % 변형 수`. 저장 필드 불필요 — 같은 인물은 항상
  같은 얼굴이다.
- 규격: 정사각 1해상도(UI 전용이라 표준/HD 구분 불필요), 한 시트에 모아
  `public/assets/portraits/` 아래 배치. 소형(세력 줄)과 카드(조정 창)는 같은
  원본을 축소해 쓴다.
- 후반 연결: 패자 등극 시 해당 지도자 초상이 그대로 칸의 초상이 된다 — 몇 년 본
  얼굴이 칸호를 얻는 것이 연출의 핵심이므로 **등극 시 초상을 바꾸지 않는다**.

## 4. 저장 스키마

```ts
// 부족 지도자는 시드 순수 함수라 저장하지 않아도 되지만, 역사 시계가 교체를
// 시작하면 상태가 되므로 처음부터 저장 필드로 둔다.
state.factionLeaders: Record<string, { name: string; title: string; temper: string }>;
state.borderCommander: {
  name: string;
  temper: 'strict' | 'greedy' | 'lenient' | 'tactician';
  termIndex: number;      // 부임 비트 중복 방지 겸 현재 임기
};
```

- 마이그레이션 1회 (착수 시점 최신 버전에서 +1: v47 → v48).
  구세이브는 현재 day의 임기 번호로 북병사를 즉석 생성하고, 부임 비트는 생략한다.

## 5. 구현 단계

| 단계 | 내용 | 완료 기준 |
|---|---|---|
| F1 | 인물 생성기(이름 풀·성향)·저장 필드·마이그레이션·임기 전환 처리 | **완료** — 같은 시드는 항상 같은 인물. 96일마다 교체 + 소문·연대기 1건 |
| F2 | 북병사 성향 보정 4종을 기존 다이얼에 연결 | **완료** — 의심 증감·하사 단계·청원 비용/물자·세공 유예·위협 감소 표적 테스트 |
| F3 | 명의 삽입(세공·하사·견책·감찰·개칭·협상·통첩·결산문) + 조정/세력 창 표시 | **완료** — 조정·세력·교역 UI, 세공·하사·청원, 감찰·견책·개칭, 통첩·습격 결산문까지 대표 명의 연결 |
| F4 | 초상 풀 16종 생성(§3-1)·시트 연결·조정/세력/협상 창 표시 | 성향-초상 일치 육안 확인, 결정적 배정 테스트 |

F1+F3만으로도(보정 없이) 몰입 목적은 달성된다 — F2·F4가 밀리면 그 상태로 내보내도
된다. F4는 아트 생성이 독립 작업이라 다른 단계와 병행 가능하다.

## 6. 비범위 (하지 말 것)

- 인물별 우호도·호감 게이지 — 수치는 세력/조정 단위 유지
- 부족 지도자의 교체·계승 — 역사 시계(후반 엔딩 계획) 소관
- 개인별 전용 초상 — 초상은 성향 풀(§3-1)을 돌려쓴다. 인물마다 새로 생성하지 않는다
- 왕·중앙 조정 인물 — 등장하지 않는다 ("조정"은 계속 추상 명의)
- 감찰 어사 개편 — 이미 사건 단위 인물이므로 그대로
- 부족 지도자 성향의 수치 보정 — 오래가는 인물의 영구 보정은 밸런스 왜곡 (§0-2)
