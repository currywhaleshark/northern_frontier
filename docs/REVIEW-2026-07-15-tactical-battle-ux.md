# 수동전투(전술 전투) 흐름 검증 및 수정사항 — 2026-07-15

> 역사 문서 상태 (2026-07-18): 아래 체크박스는 최초 리뷰 당시 기록이다. 현재 전술 UI와
> 회귀 검증 상태는 [UI 재구성 릴리스 후보](release-candidates/2026-07-ui-reorganization.md)를 기준으로 한다.

브랜치 `codex/combat-system-expansion` 기준. 전투 시뮬레이션 모드로 실제 플레이하며 검증한 결과와
수정 목록을 정리한다. 완료 시 각 항목의 체크박스를 갱신할 것.

## 검증 방법

- 메인 메뉴 → 전투 시뮬레이션.
- **마을 방어전**: 니마차 우디캐 / 수비병 요격 / 경보됨 / 적 전력 75 / 겨울·서리 / 아군 지정(기본 편성).
  준비태세 3종(주민 대피·목책 응급 수리·사냥꾼 매복 배치) 선택 후 5교전 전체 지휘·관전.
- **늑대 사냥**: 랜덤 조건. 준비(함정 설치) → 배치(길목 지정 검증) → 1교전.
- 뷰포트 1280×720. 콘솔 에러 0건, 진행 불능·소프트락 없음.

### 정상 동작 확인 항목 (수정 불필요)

- 단계 전환: 준비태세 → 준비 실행 연출 → 배치 → 교전 지휘 → 재생 → 교전 보고 → 전투 장계.
- 명령 지정 시 다음 '명령 대기' 부대로 자동 선택 이동 + 무대가 해당 구역으로 스크롤.
- 기본 명령 자동 배정 → 명령 없이 "교전 개시"만 눌러도 라운드 진행 가능.
- 사용 불가 명령의 사유 툴팁(무기/구역/전열 조건), 표적 지정 토글(적 클릭)과 자동 표적 복귀.
- 후방 급습 대응 안내 패널(후열 쪽 재배치 / 후열 원거리 대응 / 무대응) 노출과 부대 선택 연결.
- 매복 → 급습 → 적 선봉 혼란, 적 통과 후 뒤처진 조의 자동 후퇴 합류, 스페이스/클릭 배속 재생.
- 사냥: 함정 길목 미지정 시 전투 시작 차단(사유 툴팁), 사냥 전용 명령 라벨(창벽·몰이 등)과
  보고 그리드(짐승 피해·포위망).

  - 같은 열 충돌 여부와 무관하게 축소됨
  - 후방 급습대 수까지 아군 밀집도로 계산됨
  따라서 먼저 `formationGroupCount`를 **같은 열의 그룹 수(`lineGroups.length`) 기준**으로
  바꾸고, 후방 급습으로 영역 폭이 줄어드는 효과는 **별도 `compact` 조건**으로 분리할 것.
- **수정안** (선행 변경 후, 효과 대비 비용 순):
  1. 라벨 충돌 해소: 같은 열 2개 조 이상이면 라벨 세로 어긋나기 배치, 또는

     **주의: 간격 공식은 `tools/game/test_tactical_components.mjs:174`에 정규식으로 정확히
     고정돼 있음** (`Math\.min\(96, 44 \+ Math\.max\(0, groupCount - 2\) \* 16\)`) —
     수정 시 반드시 테스트를 새 간격 계약으로 함께 갱신.
  3. 밀집 축소 티어(`denseFormation`, `:340-344`)를 같은 열 2~3개부터 발동.
  4. (중기) 배치·지휘 단계에서 열을 가로 3분할 대신 깊이(위아래 원근) 배치로 전환해
     열마다 가로 폭 전체 사용. 연출 단계는 현행 유지.
- **테스트 매트릭스**: 같은 열 1/2/3개 조, 서로 다른 열에 1개씩 3개 조, 후방 급습 상태
  각각에 대해 축소 발동 여부·간격 검증.
- **파일**: `src/components/tactical/TacticalZoneColumn.tsx:269-281`, `:340-344`, `:973`,

  1. 무손실 시간 종료를 `defenseSuccess`로 판정
  2. 별도의 교착/불완전 방어 outcome 신설
  3. `partialLoss` 유지하되 구체적 손실이 없으면 다른 요약 문구 사용
  (실피해 0 문구 교체만으로는 라운드 결과와 최종 승패의 의미 차이가 남음)

## 공격→피해 체인 검토 (개편 결과 확인)

이벤트 조립 순서: `아군 행동 → 적 사상 → 혼란/퇴각 → 적 행동 → 아군 사상 → 기동`
(`src/game/tacticalEngagement.ts:973-981`). 관전 시 인과가 끊기지 않고 읽히며,
쓰러진 적의 행동 이벤트 필터링(`survivingAttackerIds`, `:928-941`) 덕에 '죽은 적의 반격'이
없다. **개편 방향 유효 — 구조 변경 불필요.** 다듬을 것 2건:

- [ ] 피해 자막의 0 노출: `"전사 0, 부상 1명이 발생했습니다"` — 플로트 텍스트(`:886`)처럼
  자막(`:882`)도 0인 항목을 생략.
- [ ] 연속 casualty의 동일 문형 반복 완화 — **이벤트 병합 금지, 자막만 묶을 것**.
  각 casualty 이벤트는 단일 `groupId`·`wounded`·`killed`를 갖고,
  `tacticalEngagement.ts:879`와 `TacticalZoneColumn.tsx:947`(casualty-hit 점멸),
  `playbackCasualties`(그룹별 쓰러짐 연출)가 이 키에 의존한다. 이벤트를 합치면 병합에서
  빠진 부대의 쓰러짐·점멸 연출이 사라짐. `tools/game/test_tactical_components.mjs:199-205`가
  그룹별 점멸 계약을 고정하고 있음. → **이벤트는 그룹별로 유지하고 표시 자막(text)만
  묶어서 생성** ("적 선봉·노획조에서 3명이 쓰러졌습니다").
  **통합 자막 계약**: 연속한 동일 진영 casualty 구간의 각 이벤트가 **같은 통합 caption을
  반환**하게 한다(재생 중 이벤트가 넘어가도 자막이 바뀌지 않고 유지되도록). 생성 시점에
  구간을 찾아 동일 문자열을 각 이벤트 text에 넣는 방식이 소비자 수정 없이 가장 안전.

## 참고 관찰 (수정 여부는 설계 판단)

- **초반 템포**: 5교전 중 1~2교전이 접근·기동만으로 소비됨(급습 성공으로 적 선봉 혼란 영향 포함).

  (`TacticalBattleScreen.tsx:961`은 방어전에서 `buildingsDamaged`를 표시).
  사냥·토벌처럼 칸으로 노출하면 라운드 성과가 한눈에 들어옴.
