# 재해 확장 D6 — 설해 구현계획

> **계획 상태:** 완료

- 담당 모델: `gpt-5.6-terra`
- 추론 수준: `high`
- 원칙: 결정적 날씨표를 다시 굴리지 않고, 실제 당일·전날 날씨만으로 판정한다.

## 확정 범위

- 겨울에 `heavySnow` 또는 `blizzard`가 실제로 이틀 연속 이어진 둘째 날 설해가 한 번 발생한다.
- 같은 겨울에는 한 번만 판정하며, 구 저장도 안전한 기본값으로 이어 간다.
- 완공된 움집은 높은 확률, 온돌집은 낮은 확률로 파손된다. 기와집은 설해 파손 면제다.
- 피해 건물은 기존 수리 상태와 건설담당 수리·입주자 재배치 흐름을 그대로 쓴다.
- 선택지는 없으며, 피해 규모와 수리 필요성은 로그·상단 경보·연대기에 남긴다.
- 겨울 날씨 오버레이와 기존 파손 스프라이트를 시각 표현으로 재사용한다.
