# 재해 확장 D8 — 가축 돌림병 구현계획

> **계획 상태:** 완료
> **상태 갱신:** 2026-07-29 — 축종군별 축사 감염·도살 처분·격리와 목동 간호, 농우·군마 정합성, 저장·경보를 구현하고 표적 회귀와 빌드를 완료했다.

- 담당 모델: `gpt-5.6-terra`
- 추론 수준: `high`
- 원칙: 기존 축사 재고·도축·농우·군마 정합성 경로를 재사용하고, 가축 손실을 별도 수량 조작으로 흩뜨리지 않는다.

## 확정 범위

- 사육 중인 축종군을 두수 비중으로 추첨해 우역(소·양·염소), 저역(돼지), 계역(닭), 마역(말) 중 하나를 발생시킨다.
- 최초 감염 축사에서 매일 폐사가 나며, 같은 축종군의 다른 축사로 전염될 수 있다.
- `도살 처분`은 감염 축사의 일정 비율을 기존 도축 경로로 즉시 처리해 고기·가죽을 회수하고 확산을 끝낸다.
- `격리하고 버틴다`는 목동이 돌보는 동안 낮은 확률로 자연 회복하지만, 목동이 없거나 폐사가 이어지면 전멸할 수 있다.
- 소·말 손실은 기존 농우 배정·군마 배정 정합성을 자동으로 갱신한다.
- 구 저장은 활성 돌림병 상태가 없으면 안전한 기본값으로 이어 간다.

## 검증

- 두수가 많은 축종군이 발생 추첨에서 더 큰 비중을 갖는지 확인한다.
- 우역이 소·양·염소 축사 사이에서만, 나머지 역병은 같은 축종 사이에서만 번지는지 확인한다.
- 처분이 기존 도축 산출과 농우·군마 재배정을 보존하는지 확인한다.
- 격리 중 목동 유무가 폐사·회복·타 축사 전염에 영향을 주는지 확인한다.
- 구 저장형 `incidents`가 새 상태 기본값으로 정규화되는지 확인한다.
