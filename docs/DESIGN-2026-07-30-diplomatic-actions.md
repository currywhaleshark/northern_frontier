# 외교 활동 — 예물·맹약·귀띔·근접 경고·협정·원병 (설계)

> **계획 상태:** 완료
> **상태 갱신:** 2026-07-30 — E1~E6을 구현·검증했다. E6은 산채 원병의 자동·직접
> 전투 합류와 부족 전쟁 민병 파견·결산, v52 저장까지 반영했다.

- 작성: 2026-07-30
- 전제: 외교 인물 계획(DESIGN-2026-07-30-diplomatic-figures.md)과 짝이다 — 모든
  활동의 수신인은 그 계획의 지도자들이고, 성향이 답신 문체를 정한다.
- 동기: 세력 상호작용이 교역과 습격뿐이다. 우호도를 "움직일 수 있는" 능동 수단과,
  우호도가 높을 때의 체감 보상을 만든다.

## 0. 원칙

1. **기존 다이얼만 움직인다.** 우호도·위협도·습격 트리거·의심·영역 긴장.
   새 게이지를 만들지 않는다.
2. **친여진 행동은 의심을 먹인다.** 예물·맹약·원병은 조정 의심을 함께 올린다 —
   외교는 공짜 우호도 버튼이 아니라 **근왕/귀부 노선의 조향 핸들**이다
   (후반 엔딩 계획 §3의 조건 축과 직결).
3. **결정적 판정.** 성공 확률 게이트 없음 — 효과는 품목 가치·우호도 문턱의
   결정적 함수다 (엔딩 계획 §0-1과 정합).
4. **사절은 오간다.** 개칭 파발처럼 왕복 일수가 있다. 여진 세력은 국경 인접이라
   짧게 — `CONFIG.diplomacy.envoyTravelDays = 6` (초안).
5. **조정 방면은 현행 유지.** 세공·청원·의심이 이미 조정 외교다. 새 활동 없음.

## 1. 활동 6종

### A1. 예물 사절 (능동 · 우호도 매수)

- 세력 창에서 품목·수량을 골라 사절을 보낸다. 왕복 후 우호도 상승 —
  상승폭은 세력별 가치표(`factionValue`)로 환산한 예물 가치의 결정적 함수.
- **품목 제한: 사치품과 은만 받는다** — `LUXURY_RESOURCES`(자기·유기·칠기·비단·
  귀금속) + `silver`. 곡물·가죽 같은 생필품은 예물이 아니라 거래다 — 잉여 물자로
  우호도를 사는 우회로를 막고, 사치품에 교역 소비처 외의 사용처가 하나 생긴다.
  예물의 격(格)이라는 표현도 자연스럽다: "족장에게 곡물 스무 섬"은 모욕이지만
  "비단 두 필"은 예물이다.
- **체감 규칙**: 세력당 계절 1회. 같은 해 두 번째부터 상승폭 절반 (뇌물의 한계효용).
- **의심 연동**: 예물 1회당 의심 소폭 상승. 기존 월경 교역 혐의(`initiatedTradeDays`)
  와 같은 결로 "먼저 손 내민 접촉"으로 기록된다.
- 답신 1줄이 지도자 성향으로 갈린다 (호방: "화끈하군" / 노회: "뜻은 받되 값은
  기억하겠다" 류).

### A2. 화친 맹약 (능동 · 불가침)

- 조건: 우호도 60 이상 + 예물 동봉. 체결 시 **그 세력의 습격·강탈 트리거가
  N년(우호도에 비례, 2~4년) 정지**한다.
- `state.diplomaticPacts: { factionName, untilDay }[]`. 세력 창에 맹약 배지와 잔여 표시.
- **내가 깨는 조건**: 그 세력 산채 원정, 생활권 침해 긴장 폭발 → 맹약 파기 +
  우호도 대폭락 + 위협 급상승 (배신의 대가는 무거워야 약속이 게임 요소가 된다).
- **의심 연동**: 체결 시 의심 큰 폭 상승 — 여진과의 강화는 조정이 가장 싫어하는 일.
- 만료 계절에 갱신 제안 이벤트 (정기거래 갱신 모달 관례 재사용).

### A3. 습격 귀띔 (수동 · 우호도의 지속 보상)

- 우호도 70 이상인 세력이 있으면, **다른 세력**의 습격이 뜰 때 며칠 전 귀띔이
  온다("○○ 족장이 사람을 보내 일렀다 — 그믐께 △△가 움직인다"). 그 습격은
  경고된(warned) 습격으로 발생한다.
- 확률 없음 — 문턱 충족 시 항상. 이미 warned/unwarned가 기계적으로 다르므로
  (`openRaidChoice`의 warned 인자) 구현은 트리거 앞단 분기 하나다.
- 귀띔 자체가 우호 세력의 존재 가치를 매일 증명한다 — 예물·맹약의 투자 회수처.

### A4. 근접 경고 (수동 · 마찰의 사전 단계)

직접 침해 전에 "지켜보고 있다"가 온다. 기존 영역 시스템(claimZones의 긴장,
territory의 위반 판정)의 **앞단에 완충 단계**를 추가한다.

- **생활권 완충 반경**: 생활권 경계 밖 2~3칸 이내에 건물을 완공하거나 주민이
  반복 작업(같은 완충 칸에서 누적 N일)하면 항의 사절 — 지도자 명의의 경고 이벤트
  1회. 무시하고 계속하면 긴장 소폭 누적 (기존 침해보다 약하게).
- **산채·세력 거점 주변**: 주민·원정대가 거점 반경 N칸에서 누적 며칠 어슬렁거리면
  경고("○○의 전사들이 너희를 지켜보고 있다"). 계속하면 관계 하락 + 위협 소폭 상승.
- 경고는 세력당 같은 사유로 1회만 (도배 방지 — dedupe는 연대기 관례처럼 키로).
- 구현 앵커: `claimZones.ts`(dailyClaimTensionTick·noteBuildingClaimIntrusions),
  `territory.ts`(noteTerritoryViolation·updateTerritoryWarnings)에 완충 판정 추가.
- 항의·경고는 로그 + 중앙 플로트(기존 actionNotice)로 눈에 띄게.

### A5. 생활권 협정 (능동 · 채집권 구매)

- 은 또는 물자를 내고 특정 생활권의 **채집·작업 권리를 연 단위로 산다**.
  협정 중에는 그 구역 작업이 긴장·경고를 만들지 않는다.
- `state.claimAccords: { zoneId, untilDay }[]`. 만료 시 알림, 갱신은 다시 사절.
- 가격은 구역 크기·세력 우호도의 결정적 함수 (우호도 높으면 쌈).
- A4의 완충 경고와 짝: 경고 이벤트의 선택지에 "협정을 제안한다"를 넣어
  마찰 → 외교의 자연스러운 도선을 만든다.

### A6. 원병 (능동+수동 · 군사 외교)

- **요청**: 우호도 80 이상 세력에 산채 토벌 원병을 청한다 — 여진 전사 N명이
  원정대에 임시 합류 (전투 로스터에 외부 전투원, 아라개 계열 스탯 재사용).
  대가: 물자 + **의심 대폭** (여진 병력을 빌리는 변방관이라니).
- **참전 요청**: 세력이 자기들끼리의 분쟁에 참전을 청해 온다 (부족 전쟁의 존재를
  후반 역사 시계 전에 미리 보여주는 장치). 응하면 민병 파견 — v1은 전술 전투 없이
  **추상 판정**: 며칠 뒤 결과 이벤트(사상자·전리품·요청 세력 우호도 대폭↑·상대
  세력 우호도 대폭↓·의심↑). 거절해도 불이익 없음(소폭 실망만).
- 파견 중 민병은 원정대처럼 마을 방어에서 빠진다 — 위험 부담이 실재해야 한다.

## 2. UI

- **세력 창(FactionsWindow) 확장**: 세력마다 행동 줄 — 예물 보내기 · 맹약 제안 ·
  원병 요청 (조건 미달은 사유 툴팁과 함께 비활성). 맹약·협정 배지와 잔여 일수.
- 진행 중 사절은 세력 줄에 "사절 왕복 중 (○일)" 표시.
- 경고·항의는 이벤트 모달(지도자 명의) 또는 중요 로그 + 중앙 플로트.
- 모든 문구에 지도자 이름·성향 대사 — 인물 계획 F3과 같은 결에서 작업.

## 3. 저장 스키마

```ts
state.diplomaticPacts: { factionName: string; untilDay: number }[];
state.claimAccords: { zoneId: number; untilDay: number }[];
state.pendingEnvoys: {
  factionName: string;
  kind: 'gift' | 'pact' | 'aidRequest';
  payload: Partial<Record<ResourceId, number>>;
  dueDay: number;
  pactYears?: 2 | 3 | 4; // 맹약 사절 출발 시 고정한 불가침 기간
}[];
state.proximityWarnings: string[]; // 세력×사유 dedupe 키
state.proximityWarningProgress: Record<string, number>; // 완충 작업·거점 배회의 누적 일수
```

- v49는 사절·맹약·협정·경고 dedupe 배열을, **v50은 E4 누적 진행값**을 넣는다.
  v49 구세이브의 진행값은 빈 객체에서 시작한다.

## 4. 구현 단계

| 단계 | 내용 | 완료 기준 |
|---|---|---|
| E1 | 사절 골격(pendingEnvoys·일일 처리) + 예물(A1) + 의심 연동 | **완료** — 예물 → 왕복 → 우호도·의심 변동, 계절 제한·연차 반감·v49 마이그레이션 표적 테스트 |
| E2 | 화친 맹약(A2): 체결·습격 정지·파기·갱신 | **완료** — 가치 12 이상 동봉 예물·6일 사절·관계별 2~4년 불가침, 습격/강탈 제외, 생활권 항의 묵살·해당 세력 산채 원정 파기, 만료 갱신과 표적 테스트·빌드 |
| E3 | 습격 귀띔(A3) | **완료** — 우호 70+의 다른 세력이 지도자 성향 대사로 귀띔하고 협박 거절 뒤까지 warned 유지 |
| E4 | 근접 경고(A4): 생활권 완충 + 거점 어슬렁 | **완료** — 경계 바깥 2칸 완충의 건물 완공/3일 작업, 발견 거점 외곽 3칸의 3일 배회, 세력×사유 1회 경고·4일 간격 약한 압박·중앙 플로트·v50 저장을 표적 회귀·빌드로 검증 |
| E5 | 생활권 협정(A5) + A4 경고 선택지 연결 | **완료** — 구역별 6일 사절·반경/관계 결정 가격·1년 권리, 통행/사냥 즉시허가 통합·통행 길/교역 보너스, 실제 접촉/침범 구역과 취소·실패 비용 보존, v51·E5/E4/E2 표적 회귀·빌드 |
| E6 | 원병(A6): 토벌 합류 + 참전 요청 추상 판정 | **완료** — 관계 80+ 원병 사절·결정 군량·외부 전술조, 자동/직접 토벌 공통 전력, 연차별 부족 전쟁 파견·노동/방어 제외·결정 사상자/전리품/관계/의심·결과 장계, v52·표적 회귀·빌드 |

각 단계가 독립 출하 가능하다. E1~E3이 우선 (구현 가볍고 후반 조향 효과 즉시).

## 5. 후반 엔딩과의 연결

- 예물·맹약·원병이 귀부 조건 축(패자 우호 高)의 능동 레버가 되고, 그 대가인
  의심 상승이 근왕 축(조정 관계)과의 트레이드오프를 만든다.
- A6 참전 요청은 역사 시계 1막(부족 전쟁 격화)의 사전 학습이다 — 플레이어가
  "부족끼리 싸운다"를 이미 아는 상태로 통일 전쟁 소문을 듣게 된다.
- **정략혼은 이 계획의 범위가 아니다** — 후반 엔딩 귀부 루트의 일회성 이벤트
  (게이트 수락 연출 또는 조건 보조)로 편입한다. 후반 엔딩 계획 §9에 기록.

## 6. 비범위 (하지 말 것)

- 조정 방면 신규 활동 — 세공·청원·의심 현행 유지
- 정략혼·볼모 — 후반 엔딩 귀부 루트 소관 (일회성)
- 세력 간 상시 전쟁 시뮬레이션 — 참전 요청은 이벤트+추상 판정까지만
- 인물별 우호도 게이지 — 인물 계획과 동일 원칙
- 확률 게이트 — 모든 판정은 결정적
