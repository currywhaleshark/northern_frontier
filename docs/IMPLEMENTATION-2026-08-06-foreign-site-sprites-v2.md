# 외부 거점 경사 탑뷰 스프라이트 v2 구현계획

> **계획 상태:** 완료
> **상태 갱신:** 2026-08-06 — 외부 거점 본체 5종과 부속물 7종의 경사 탑뷰·겨울·표준/HD 자산을 생성해 런타임과 스프라이트 스튜디오에 연결하고 픽셀 검사·최대 줌·빌드를 검증했다.

- 관련 설계: [타 부족 거주지 활동 설계](DESIGN-2026-08-06-foreign-site-activity.md)

- 관련 제작 도구: `sprite-gen`, 스프라이트 스튜디오 자산 감사

## 1. 목표

1. 정직한 탑다운인 외부 거점 구형 자산을 플레이어 정착지 건물과 같은 경사 탑뷰로 교체한다.
2. 지붕뿐 아니라 남쪽 정면과 동쪽 측면이 읽히되, 아이소메트릭 다이아몬드나 원근 왜곡은 쓰지 않는다.
3. 최대 줌에서도 선명하도록 표준·HD 시트를 함께 제공한다.
4. 캔버스 선과 도형으로 임시 묘사되는 건조대와 나룻배도 동일한 화풍의 스프라이트로 교체한다.
5. 스프라이트 스튜디오의 자산 감사에서 새 표준·HD 시트가 실제 런타임 사용 자산으로 표시되게 한다.

## 2. 자산 계약

### 2-1. 본체 시트

| 열 | 대상 | 시각적 구분 |
|---:|---|---|
| 0 | 오도리 씨족 부락 | 농경 정주지, 초가와 낮은 울타리·작은 텃밭 |
| 1 | 올량합 부락 | 농경과 수렵이 섞인 목재·초가 복합 부락 |
| 2 | 골간 우디캐 어로 부락 | 어망·통발·물고기 건조 흔적이 있는 강변 취락 |
| 3 | 니마차 우디캐 계절 사냥터 | 원형 천막·가죽·화덕이 읽히는 임시 야영지 |
| 4 | 변경 마적 산채 | 목책·감시대·붉은 천이 있는 방어 거점 |

- 행 0은 평상, 행 1은 겨울이다.
- 논리 표시 크기는 `56×80`, 표준 소스 셀은 `112×160`, HD 소스 셀은 `448×640`이다.
- 모든 셀은 2×2 타일 발자국의 왼쪽 아래를 기준으로 정렬한다.

### 2-2. 부속물 시트

| 열 | 대상 | 런타임 용도 |
|---:|---|---|
| 0 | 오도리 부속 오두막·창고 | `hut`, `storehouse` |
| 1 | 올량합 부속 오두막·창고 | `hut`, `storehouse` |
| 2 | 골간 어로 저장막 | `hut`, `storehouse` |
| 3 | 니마차 사냥막 | `huntLodge` |
| 4 | 변경 마적 부속막 | 향후 산채 부속 및 호환 폴백 |
| 5 | 생선 건조대 | `dryingRack` |
| 6 | 전통 한선형 나룻배 | `boat` |

- 행 0은 평상, 행 1은 겨울이다.
- 논리 표시 크기는 `28×40`, 표준 소스 셀은 `56×80`, HD 소스 셀은 `224×320`이다.
- 나룻배는 강 타일 안에서 읽히도록 물이나 지면 배경을 포함하지 않고 선체만 남긴다.

## 3. 미술 방향

- 지면 시선각은 약 55°로 고정해 지붕·정면·동쪽 측면이 동시에 보이게 한다.
- 플레이어 건물의 따뜻한 민속 픽셀아트 팔레트와 1px 윤곽 밀도를 따른다.
- 15~17세기 동북아 변경의 목재·흙·초가·가죽 재료를 사용하며 서양·일본 성곽·중국식 정크선 인상을 피한다.
- 각 셀은 완전한 실루엣과 충분한 투명 여백을 가지며, 지면·하늘·그림자 평면·문자·프레임 구분선을 넣지 않는다.
- 겨울은 같은 구조와 구도를 유지하고 지붕·목책·배 안쪽에만 얕은 적설을 더한다.

## 5. 완료 판정

- 다섯 외부 거점의 구분이 기본 줌과 최대 줌 모두에서 유지된다.
- 모든 새 시트의 모서리는 투명하고 마젠타·녹색 크로마 잔색이 없다.
- 평상/겨울 행과 표준/HD 프레임의 열 의미가 일치한다.
- `dryingRack`, `boat`가 더 이상 캔버스 도형으로 그려지지 않는다.
- 스프라이트 스튜디오 자산 감사에서 새 PNG가 `used`로 판정된다.
- 표적 픽셀 검사, 스프라이트 타입 검사, 프로덕션 빌드가 통과한다.
