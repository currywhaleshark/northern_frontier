## 0. 목표

메인 메뉴를 얇게 하고(시작·튜토리얼·전투 시뮬레이터·설정), **시작 → 시작 설정창**을 거치게 한다. 설정창에서 마을 이름·난이도에 그치지 않고 **지역 타입·지도 크기·자원 밀도**까지 세부 조절한다. 리플레이의 축을 "난이도 하나"에서 "지형·규모·풍요도의 조합"으로 넓히는 것이 목적이다.

## 1. 현재 기준선 (2026-08-01 코드 대조)

| 항목 | 현재 |
|---|---|
| 메인 메뉴 | 난이도 3종 카드·이름 입력이 메뉴 화면에 직접 노출. 버튼: 개척 시작 / 길잡이 / 전투 시뮬레이션 / 설정 |
| 지도 | `CONFIG.map` 72×72 고정. 렌더러·미니맵은 대체로 `state.map` 치수를 읽지만 72 가정 지점 전수 감사 필요 |
| 지형 | forest·plain·river·mountain·fertile·rock·center — **바다·호수 없음** |
| 소금 | `salt` 자원 실재 (염장 자반·김장 소비처 있음). 국내 생산 없음 — 교역 수급 |
| 생성 파라미터 | 광물 매장량·서식지·수맥 등이 CONFIG 상수로 이미 파라미터화 — 배율 노출이 자연스러움 |

## 2. 확정 방향

### 가. 메뉴·설정창 구조
- 메인 메뉴: **시작 / 튜토리얼 / 전투 시뮬레이터 / 설정** 4버튼만.
- 기존 저장이 있으면 **이어하기**는 네 주요 진입점과 별도의 조건부 보조 버튼으로 유지한다. 시작 설정창으로
  불러오기를 섞거나 기존 저장 진입을 없애지 않는다.
- 「시작」 → 시작 설정창: 마을 이름(주사위 재굴림 유지) · **난이도 프리셋 3종** · **지역 타입** · **지도 크기** · **세부설정(접기)**. 튜토리얼은 설정창을 거치지 않고 고정 시드 그대로.
- **난이도 = 프리셋, 세부설정 = 노브** (2026-08-01 사용자 확정): 난이도 카드(이주민/개척민/변방 첨사)는 세부 노브 값의 묶음이다. 「세부설정」을 펼치면 개별 노브 — 시작 물자, 자원 밀도(광물·숲·서식지·수맥), **기후 혹독도**(온화/기준/혹독 — 결정적 연간 기후에 배율), 위협(습격 빈도·규모) — 를 따로 조절할 수 있고, 노브를 하나라도 바꾸면 프리셋 표시가 「사용자 설정」으로 바뀐다. 지역 타입·지도 크기는 난이도가 아니라 정체성 선택이므로 프리셋 밖의 독립 항목으로 둔다.
- 선택한 설정(프리셋명 또는 사용자 설정 + 노브 값)은 저장에 기록하고 연대기 첫 줄의 문맥으로 남긴다("한원촌 — 해안의 소형 개척지").

### 가-1. 시작 옵션 데이터 계약

- UI와 시뮬레이션 사이에는 `NewGameOptions` 한 객체만 전달한다. 이름·프리셋·지역·크기·시드와
  세부 노브의 **실효값 스냅샷**을 함께 담아, 이후 CONFIG가 바뀌어도 이미 시작한 저장의 조건은 유지한다.
- `GameState.worldSetup`에 같은 정규화 결과를 저장한다. 기존 저장은 `평원·중형·기존 difficulty에서
  파생한 실효값`으로 보정한다.
- 현행 `newGame(seed, difficulty, settlementName)` 호출은 테스트·도구 호환 래퍼로 남기고,
  새 UI만 `newGameFromOptions(options)`를 사용한다. S0+S1에서 기존 게임 밸런스와 지도 RNG 순서는 바꾸지 않는다.
- 저장 슬롯에는 지역·크기·프리셋(또는 사용자 설정)을 표시하고, 창건 연대기에는
  `평원의 중형 개척지` 같은 문맥을 한 번만 기록한다.

### 나. 지도 크기 — 소형 / 중형 / 대형
- **중형 = 현행 72×72** (기존 밸런스·테스트의 기준선 유지). 소형·대형 치수는 성능 감사와 함께 확정 (초안: 소형 56², 대형 96²).
- 감사 항목: 바닥 캐시·경로 탐색·goal field의 면적 비례 비용(프레임 페이싱 이력), 미니맵 축척, 위협·탐사·습격 이동 시간의 페이싱, 저장 크기. `CONFIG.map` 직접 참조를 `state.map` 치수 참조로 정리.

### 다. 지역 타입 — 평원 / 산지 / 호수 / 해안
각 타입은 뚜렷한 한 축을 얻고 한 축을 잃는다. 평원이 기준선.

| 타입 | 얻는 것 | 잃는 것 | 구현 비용 |
|---|---|---|---|
| 평원 (현행) | 균형 | — | 0 (기준선) |
| 산지 | 내부 능선·숲·광물·사냥감↑ | 경작지·평지·강·일반 수맥↓ | 중간 — 지형 프로필과 수맥·광맥·서식지 region 연결 |
| 호수 | 자연 급수권↑(호반 논), 후일 어로 | 숲/평지 일부 | 중간 — 'lake' 수역 지형 신설, 급수권은 강 3칸 문법 재사용, 오토타일 아트 |
| 해안 | **소금 자급** | **농사용 물 부족** | 높음 — 'sea' 지형·해안선 아트·소금 생산 체인·물 밸런스 축 |

산지는 평원의 동·북쪽 둘레 산 배치를 그대로 확대하는 데 그치지 않고, 정착지 안전 반경 밖으로
능선이 지도 내부까지 들어온다. 강과 비옥지, 일반 수맥은 줄지만 시작 수맥 하나는 보장한다. 숲과
접근 가능한 산자락 노두, 지하 광맥, 사냥 서식지는 늘려 광업·임업·수렵 중심의 정체성을 만든다.

### 라. 해안의 밸런스 (사용자 구술 + 검토 보강)
- **소금 자급 = 자염(煮鹽)**: 해안에만 지을 수 있는 자염막이 바닷물을 **장작으로 끓여** 소금을 낸다. 소금은 공짜가 아니라 장작 경제와 맞물린다(북방 겨울의 장작 긴장이 소금 생산과 경쟁 — 고증도 정확). 염장·김장·자반의 기존 소비처와 교역 가치가 즉시 판로가 된다.
- **농사용 물 부족**: 해안 지도는 수맥 밀도·우물 산출을 낮추고 강을 짧게(또는 기수역 표현) — 밭은 되지만 논이 귀하고, 우물 투자가 커진다. 식량은 어물·교역(소금 판매) 축으로 기운다.
- 결과: 평원=농본, 산지=광공, 호수=수리·어로, 해안=제염·교역이라는 네 정체성.

### 마. 세부설정 노브
- 각 노브는 자유 슬라이더가 아니라 **단계 선택**(예: 부족/보통/풍부, 온화/기준/혹독) — 밸런스 보증과 결정론(시드+옵션 → 동일 지도) 유지. 기존 CONFIG 상수에 배율만 곱한다.
- 첫 판 노브 목록(확정): **시작 물자 / 통합 자원 밀도 / 기후 혹독도 / 위협**. 통합 자원 밀도는
  광물·숲·서식지·수맥을 함께 움직이고, 개별 분리는 후속이다. 난이도 프리셋 3종은 이 노브들의 사전 조합이다.
- 시드 직접 입력은 세부설정에 노출한다. 빈 값은 무작위 시드, 정수 입력은 같은 옵션과 결합해 같은 지도를 만든다.
- S0+S1에서는 현행 밸런스를 그대로 스냅샷으로 기록한다. 아직 소비처가 연결되지 않은 지역·크기·세부 노브는
  `준비 중`으로 명시해 선택할 수 없게 하고, 해당 단계가 구현될 때 순서대로 활성화한다.

## 4. 경계·주의

- **결정론**: 지도 생성 옵션은 전부 시드 파생 난수에 곱하는 방식 — 같은 시드+옵션이면 같은 지도. 회귀 테스트가 조합별 불변식(시작 수맥·노두·서식지 보장)을 검증.
- **시작 보장 지물**: 마을 옆 노두·수맥·서식지 보장은 모든 타입·크기에서 유지 — 타입은 "비율"을 바꾸지 "보장"을 깨지 않는다. (해안의 물 부족도 시작 우물 자리 하나는 보장한 위에서의 희소성.)
- **저장 호환**: 기존 저장은 중형·평원으로 간주 — 마이그레이션은 표기용 필드 기본값뿐.
- **튜토리얼**: 고정 시드·중형·평원 유지. 설정창 미경유.
- 초회 도움말(guides): 자염막 등 신규 체인은 첫 등장 안내 모듈 추가 대상.
