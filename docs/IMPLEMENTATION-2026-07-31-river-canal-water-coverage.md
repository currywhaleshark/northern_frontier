# 강·농수로 급수권 구현계획

> **계획 상태:** 완료
> **상태 갱신:** 2026-07-31 — 강·농수로 급수 판정과 레이어 표시를 구현하고 표적 회귀·최종 빌드를 통과했다.

- 담당 모델: `GPT-5 Codex 주 에이전트`
- 추론 수준: `high`
- 설계 기준: [우물과 급수](DESIGN-2026-07-28-wells-and-water.md)

## 목표

- 수맥 레이어에서 강의 생활 급수권을 직접 확인한다.
- 강에 연결된 완공 농수로가 인접 1칸에 생활용수를 공급한다.
- 끊겼거나 건설 중인 농수로는 마른 도랑으로 남겨 급수원으로 쓰지 않는다.
- 급수 필요 건물은 공급원을 강·농수로·우물로 구분해 표시한다.

## 구현 범위

- [x] `CONFIG.water.canalCoverageRadius = 1`로 수치 기준을 중앙화
- [x] 강 3칸·흐르는 농수로 1칸의 맨해튼 커버리지 집합 계산
- [x] 건물 점유칸 단위 급수 판정과 `강 → 농수로 → 우물` 우선순위
- [x] 농수로 급수는 수맥 소비에서 제외
- [x] 수맥 레이어·우물 배치·우물 선택 시 자연 급수권 색면 표시
- [x] 농수로 공급 건물의 색과 선택 정보 문구 구분
- [x] 연결·단절·반경·우선순위·수맥 비소비 표적 테스트
