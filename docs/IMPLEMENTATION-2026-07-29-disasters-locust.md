# 재해 확장 D3 — 황충 구현계획

> **계획 상태:** 완료
> **상태 갱신:** 2026-07-29 — 황충 기후 가중치·비공개 2~5일 누적 피해·정착지 단위 조기 수확·경보/오버레이와 표적 회귀, 프로덕션 빌드를 완료했다.

- 기준 설계: [재해 확장 설계](DESIGN-2026-07-28-disasters.md) §3-3
- 선행: D0 지연 재해 대기열, D1·D2의 경작지 재해·공유 경보/오버레이
- 권장 모델: `gpt-5.6-terra` / 추론 수준 `high`

## 확정 계약

- 여름과 초가을(가을 첫 4일)에 파종되어 자라는 논밭이 있으면 황충 후보가 된다.
- 발생 가중치는 온난·건조 기후와 재해 전용의 결정적 연차 변동을 함께 쓴다.
- `버틴다`를 고르면 발생 시 결정된 비공개 2~5일 동안, 당시 대상 경작지의 성장도를 매일 12만큼 깎는다.
  기간은 경보나 선택지에 노출하지 않는다.
- `서둘러 거둔다`는 정착지 단위로 한 번 선택하며, 당시 대상 경작지 전부에서 남은 예상 소출의 55%를 즉시 확보한다.
  이른 서리의 조기 수확 수율 계산을 공통 헬퍼로 재사용한다.
- 체류 중 대상 경작지에 황갈색 메뚜기 떼 오버레이를 그리고, 종료 시 떠났다는 로그를 남긴다.
