# 재해 확장 D4 — 가뭄과 보 구현계획

> **계획 상태:** 완료
> **상태 갱신:** 2026-07-29 — 실제 무강수 가뭄·강우 해소·농업/어획 피해·보 관개와 건설/시각 연결, 표적 회귀와 프로덕션 빌드를 완료했다.

- 기준 설계: [재해 확장 설계](DESIGN-2026-07-28-disasters.md) §3-4
- 선행: D0 지연 재해 대기열, 결정적 연간 날씨표
- 권장 모델: `gpt-5.6-sol` / 추론 수준 `high`

## 확정 계약

- 여름의 실제 무강수 3일 연속 구간에 가뭄 후보가 생기며, 발생 가중치는 고온·건조 기후일수록 높다.
- 발생 시 비공개 6~12일 동안 지속한다. 비가 오는 날은 생산 피해를 적용하기 전에 즉시 해소한다.
- 가뭄 중 무대비 논밭 성장과 어획은 평시의 45%가 된다.
- 보는 정착지 단계부터 강 위에 짓는 단칸 비통행 건물이다. 완공된 보 반경 6칸의 논밭은 가뭄 성장 배율이 72%로 완화된다.
- 가뭄은 선택 모달 없이 선포 로그·연대기·경보로 알리고, 남은 기간은 공개하지 않는다.
- 보의 전용 자산 전에는 기존 다리 계열 그림을 빌려 쓰되 물 표식을 덧붙여 구분한다.
