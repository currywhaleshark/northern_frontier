# 북새: 육진 너머 (北塞 — Beyond the Six Garrisons)

조선 후기풍 대체역사를 배경으로 두만강 이북의 혹한 개척지를 운영하는 **생존형 정착지 경영 시뮬레이션**입니다.
플레이어는 조정의 명을 받은 개척 책임자가 되어 주민의 생계와 생산, 방어, 교역, 외교를 관리하고 작은 개척지를
보(堡)·진(鎭)·부(府)로 성장시켜야 합니다.

단순히 일정 기간을 버티는 게임이 아닙니다. 계절과 날씨에 대비해 생산망을 만들고, 주민 개개인의 생활과 사기를
돌보며, 주변 세력 및 조정과의 관계를 조율하고, 습격과 맹수 및 산채를 상대로 군사 행동을 수행하는 장기 경영이
핵심입니다. 부(府) 승격이 최종 목표이며 승리 이후에도 계속 플레이할 수 있습니다.

현재 웹 기반 프로토타입으로 개발 중이며, Banished, Farthest Frontier, Settlement Survival에서 영감을 받았습니다.

## 실행 방법

```bash
npm install
npm run dev      # 개발 서버 (기본 http://localhost:5173)
npm run build    # 타입 검사 + 프로덕션 빌드
npm run preview  # 빌드 결과 미리보기
npm run test:game
```

Windows에서는 저장소 루트의 배치 파일을 더블클릭해 바로 실행할 수 있습니다.

- `run-game.bat` — 본 게임
- `run-head-box-editor.bat` — 헤드박스 편집기
- `run-sprite-studio.bat` — 스프라이트 스튜디오

기술 스택은 **TypeScript + React + Vite + HTML Canvas**입니다.

## 기본 플레이 흐름

1. 난이도를 고르고 새 개척을 시작하거나 길잡이 시나리오로 첫 겨울까지의 기본 운영을 익힙니다.
2. 식량·연료·옷·주거를 확보하고 주민을 생산 및 운반 직업에 배정합니다.
3. 계절, 날씨, 질병, 식품 부패에 대비해 저장·가공·의료 시설을 확장합니다.
4. 지도를 탐사해 다른 정착지와 세력, 광상, 산채 및 맹수의 흔적을 발견합니다.
5. 교역·외교·통행 협정 또는 군사 행동으로 주변 세력과의 관계를 관리합니다.
6. 성벽과 군사 시설을 갖추고 습격을 방어하며 토벌대와 사냥대를 편성합니다.
7. 인구·방어·비축·세공 조건을 달성해 개척지를 보, 진, 부로 승격시킵니다.

## 조작

| 입력 | 기능 |
|---|---|
| `Space` | 일시정지 / 이전 재생 속도로 복귀 |
| `1` | 1배속 |
| `2` | 3배속 |
| `B` | 건설 메뉴 열기 / 닫기 |
| `Q` | 직업 배정 |
| `W` | 가공·비축 |
| `E` | 주민 |
| `R` | 특수 주민 |
| `T` | 세력·거래 |
| `Y` | 조정 |
| `U` | 사건·기물함 |
| `Esc` | 게임 메뉴 또는 현재 창 닫기, 건설 배치 취소 |
| 마우스 드래그 | 지도 이동 |
| 마우스 휠 | 지도 확대·축소 (50%~200%) |
| 휠 클릭 | 지도 배율 100%로 초기화 |
| 지도·주민·건물 클릭 | 대상 선택 및 상황별 행동 |

휠은 지도 확대·축소 전용이며 지도 영역의 기본 스크롤과 스크롤바는 잠겨 있습니다. 지도 이동은 드래그 또는
미니맵을 이용합니다. 관리 창은 이동·크기 조절·고정이 가능하며 배치는 브라우저에 저장됩니다.

## 승격과 최종 목표

### 개척지 → 보(堡)

- 5년 생존
- 인구 40명
- 직전 겨울 사망률 10% 이하
- 방어도 100
- 식량과 연료 각각 100 이상 비축
- 봉수대와 군영 건설

### 보(堡) → 진(鎭)

- 인구 60명
- 방어도 160
- 세공 3년 연속 납부
- 군영 1개와 망루 2개

### 진(鎭) → 부(府)

- 인구 100명
- 방어도 250
- 세공 5년 연속 납부
- 군영 1개, 망루 3개, 장터 1개

부 승격이 최종 승리입니다. 승격할수록 새로운 주거·생산·군사·행정 시설과 직업이 해금되고, 이주민 유입과
조정의 기대 및 외부 위협도 함께 커집니다. 모반 의심이 짙으면 다음 승격이 보류됩니다.

주민 전원 사망, 마을 중심지 파괴, 대규모 아사 또는 장기간의 인구 붕괴는 패배로 이어질 수 있습니다.

## 주요 시스템

### 지도와 주민

- 72×72 절차 생성 지도와 탐사 안개
- 숲·평지·강·산지·비옥지·광상, 계절 변화와 밤낮 표현
- 주민별 위치, 나이, 가족, 직업, 숙련도, 건강, 체온, 배고픔, 사기 및 운반 화물
- 주민이 작업장까지 이동하고 실제 자원을 운반해야 생산이 완료되는 에이전트 기반 물류
- 성장·교육·청년 활동·특수 주민 및 이주민 사건

### 생산과 생활

- 농사, 벼농사, 사냥, 어업, 벌목, 채광, 목축, 약초, 운반과 다양한 가공 직업
- 곡물·고기·생선·채소·콩·달걀·우유부터 연료·의복·도구·무기·교역품까지 이어지는 생산망
- 식품 부패와 건조·염장·발효, 김장 및 장류 가공
- 계절과 날씨에 따른 연료 소모, 체온 저하, 질병과 의원 치료
- 주민 사기와 식생활, 주거, 교육, 종교 및 승격 단계별 기대치

### 건설과 방어

- 주거·물류·농업·가공·의료·군사·행정 시설
- 시설별 작업자 슬롯과 현장 재고, 작물 및 생산품 선택
- 목책·토성·석벽과 성문을 이용한 실제 이동 경로 및 공성 방어
- 봉수대·망루의 조기 경보와 무기·수비 인력 편성

### 외교, 교역과 조정

- 북방 세력, 마적, 국내 상단과의 관계도 및 세력별 교역 가치
- 계절·관계·세력 특성에 따라 달라지는 물동량과 양방향 협상
- 영유권, 통행, 사냥권, 선물, 배상 및 외교 사건
- 매년 세공 비축과 납부, 청원, 감찰, 견책 및 모반 의심

### 위협과 전투

- 지도에 실제로 출현해 이동하는 습격대와 성벽 공성
- 병종·무기·전열·사기·지휘 명령이 반영되는 전술 전투
- 산채 정찰과 토벌대 편성, 행군, 다단계 산채 공격
- 마을에서 떨어진 큰 숲을 중심으로 출현하는 늑대와 호랑이
- 맹수 정보 수집, 사냥대 편성 및 전술 사냥
- 메인 화면의 독립 전투 시뮬레이션

## 저장, 설정과 리포트

게임 중 `Esc` 메뉴에서 다음 기능을 이용할 수 있습니다.

- 저장 슬롯 저장 및 불러오기
- 새 게임 시작
- 효과음(SE)과 배경 음악(BGM)의 개별 온오프 및 음량 조절
- 의견·제안 또는 버그 리포트 작성
- 버그 리포트에 최근 게임 기록과 진단 정보 첨부 및 전체 진단 JSON 저장

저장 데이터와 UI·오디오 설정은 브라우저 `localStorage`를 사용합니다.

## 프로젝트 구조

```text
src/
  game/        순수 시뮬레이션, 경제, 외교, 생활, 전투 및 저장 로직
  render/      지도·지형·건물·주민·전투 스프라이트 렌더링
  sound/       장면별 BGM과 효과음·환경음
  components/  게임 화면, 관리 창, 메뉴, 전술 전투와 각종 대화상자
  ui/          단축키, 확대 배율, 창 배치, 설정과 리포트 보조 로직
public/assets/
  audio/       타이틀·경영·전투 BGM과 전투 효과음
  events/      사건 삽화
  factions/    세력 및 인물 이미지
  resources/   자원 아이콘
  tactical/    전술 전투 스프라이트
  ui/          관리 메뉴 아이콘
tools/game/    게임 로직·UI 구조 테스트와 장기 시뮬레이션 도구
```

게임 밸런스의 주요 수치는 `src/game/config.ts`, 건물 정의는 `src/game/buildings.ts`, 저장 마이그레이션은
`src/game/saveLoad.ts`와 `src/game/saveSchema.ts`에서 관리합니다.

개발 환경에서는 브라우저 콘솔의 `__game.run(30)`으로 30일을 빠르게 진행하고 `__game.state()`로 현재 상태를
확인할 수 있습니다.

## 검증

```bash
npm run test:game
npm run build
```

`npm run test:game`은 저장·경제·건축·튜토리얼·방어의 핵심 회귀만 실행합니다. 전체 203개는
병합 전이나 릴리스 후보에서 `npm run test:game:full`로 확인하고, 변경 범위에 따라 아래 묶음을 추가합니다.

```bash
npm run test:game:slow     # 나머지 시스템·대형 전술·릴리스 검사
npm run test:game:balance  # 다중 시드·계절·수치 계약
npm run test:game:assets   # 아틀라스·스프라이트·렌더 레지스트리
npm run test:game:ui       # TSX·CSS·HUD 구조 계약
npm run test:game:suites   # 현재 묶음별 테스트 수
```

러너는 최대 4개 파일을 병렬 실행하고 개별 파일이 60초를 넘기면 실패로 처리합니다. 파일명 일부를
넘기면 묶음과 관계없이 해당 테스트를 찾아 실행하며, 필요하면 `GAME_TEST_WORKERS`와
`GAME_TEST_TIMEOUT_MS`로 동시 실행 수와 제한시간을 조절할 수 있습니다.

```bash
npm run test:game -- forest_habitats tutorial_scenario
```

개별 테스트는 `tools/game/test_*.mjs`에 있습니다. 장기 교역 자동 플레이 예시는 다음과 같습니다.

```bash
node tools/game/test_trade_values.mjs
node tools/game/test_trades.mjs
node tools/game/simulate_trade_autoplay.mjs --runs=24 --years=10 --modes=active
```

## 그래픽과 오디오

기본 지형과 일부 캐릭터 그래픽은 [Kenney Roguelike/RPG Pack](https://kenney.nl/assets/roguelike-rpg-pack)과
[Roguelike Characters](https://kenney.nl/assets/roguelike-characters)를 사용합니다. 두 에셋은 CC0 퍼블릭 도메인입니다.
게임 전용 자원·사건·세력·전술·UI 이미지는 `public/assets/`의 각 폴더에서 관리합니다.

사운드는 다음 두 계층으로 구성됩니다.

- 타이틀·경영·전투 장면에 따라 전환되는 BGM 재생 목록
- Web Audio API로 생성하는 경보·교역·완공·환경 효과음과 별도 전투 샘플

이미지 로드에 실패하면 렌더러가 도형 기반 임시 그래픽으로 대체합니다.

## 개발 상태

현재도 밸런스와 사용성을 다듬는 프로토타입입니다. 대규모 정착지의 성능, 장기 경제 균형, 전술 전투의 직접 지휘와
자동 판정 간 격차는 계속 검증 중이며 실제 플레이 의견은 게임 내 리포트 메뉴로 받을 수 있습니다.
