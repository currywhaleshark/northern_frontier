# 북새: 육진 너머 (北塞 — Beyond the Six Garrisons)

조선후기풍 대체역사 속, 두만강 이북 혹한 개척지를 운영하는 **생존형 정착지 경영 시뮬레이션** 웹 프로토타입입니다.
Banished / Farthest Frontier / Settlement Survival에서 영감을 받았습니다.

플레이어는 조정의 명을 받은 개척 책임자(첨사)로서, 소수의 주민과 함께 혹한의 변경에서
식량·장작·방어를 관리하며 5년을 버텨 마을을 정식 진보(鎭堡)로 승격시키는 것이 목표입니다.

## 실행 방법

```bash
npm install
npm run dev      # 개발 서버 (http://localhost:5173)
npm run build    # 타입 검사 + 프로덕션 빌드
```

기술 스택: **TypeScript + React + Vite + HTML Canvas**.

그래픽: [Kenney Roguelike/RPG Pack](https://kenney.nl/assets/roguelike-rpg-pack)과
[Roguelike Characters](https://kenney.nl/assets/roguelike-characters) (모두 **CC0 퍼블릭 도메인**, 무료)를
사용합니다. 스프라이트시트는 `public/assets/`에 포함되어 있으며, 이미지 로드 전에는
도형/이모지 임시 그래픽으로 자동 대체됩니다.

## 플레이 방법

0. **시작**: 메인 메뉴에서 난이도(이주민/개척민/변방 첨사)를 고르고 개척을 시작합니다.
   난이도는 시작 물자, 위협도 증가 속도, 습격 규모에 영향을 줍니다. 저장이 있으면 이어하기가 가능합니다.

1. **시간**: 상단의 정지/1배/3배/10배 버튼으로 속도를 조절합니다. 1년 = 4계절 × 12일.
0. **화면 이동**: 지도가 화면보다 크므로 빈 곳을 **드래그해 이동**합니다(살짝 끌면 클릭, 많이 끌면 이동으로 구분). 타일 크기는 `config.ui.tileSize`로 조절합니다.
2. **건설**: 왼쪽 건설 메뉴에서 건물을 고른 뒤 지도를 클릭해 배치합니다. (우클릭/Esc 취소)
   건축가가 배정되어 있어야 공사가 진행됩니다. 사냥막을 고르면 짐승 서식지 범위 원이,
   밭을 고르면 비옥한 땅이 금색으로 표시되어 자리를 찾기 쉽습니다.
   목책·토성·석벽은 주민 동선을 막는 성벽이며, 성문은 주민만 통과할 수 있는 출입구입니다. 성벽 계열은 타일 인스펙터에서 철거할 수 있습니다.
   숲 덩어리(8타일 이상)에는 지도 생성 때 난이도별 확률로 짐승 서식지가 자리 잡고
   발자국 표식으로 표시됩니다(마우스를 올리면 범위 확인). 어려운 난이도일수록 서식지가 귀합니다.
   사냥꾼은 서식지 범위 안의 숲에서만 사냥하며, 서식지의 숲이 클수록 수확이 좋습니다.
   벌목으로 반경 안 숲이 줄면 짐승이 떠나고, 숲이 되살아나면 돌아옵니다.
3. **직업**: 왼쪽 직업 패널에서 무직 주민을 각 직업에 +/- 로 배정합니다.
   지도 위 주민 점을 클릭하거나(반경 판정이라 정확히 안 눌러도 됩니다) 오른쪽 "주민" 탭에서
   개별 주민을 선택해 직업을 직접 바꿀 수 있습니다. 선택한 주민은 금색 테두리로 표시되고
   예정 이동 경로가 지도에 그려집니다. 주민이나 습격 무리에 마우스를 올리면 이름/작업 툴팁이 뜹니다.
4. **겨울 대비**: 가을까지 식량과 장작을 충분히 쌓아야 합니다. 겨울에는 장작 소모가 3배가 되고
   생산이 거의 멈춥니다. 온돌집은 장작이 있을 때만 체온 보너스를 줍니다.
5. **습격**: 위협도가 60을 넘으면 북방 세력의 습격이 올 수 있습니다. 피난/수비병 요격/민병 징집/공물/협상/봉수 경보 중
   선택하십시오. 봉수대·망루가 있으면 이틀 전에 경보를 받습니다.
6. **교역**: 장터를 지으면 북방 세력이 이따금 찾아오고, **세력 탭이나 장터 타일의 "거래하기" 버튼으로
   먼저 거래를 청할 수도** 있습니다 (세력별 6일 간격, 관계 35 이상 필요). 먼저 청한 거래는
   돌려보내도 불이익이 없습니다.
7. **저장**: 상단의 저장/불러오기/저장 초기화 버튼 (localStorage 사용).

### 승리 조건 (모두 동시 충족)
- 5년 생존 · 인구 40명 이상 · 직전 겨울 사망률 10% 이하
- 방어도 100 이상 · 식량/장작 각 100 이상 비축 · 봉수대와 군영 건설

### 패배 조건
- 전원 사망 · 마을 중심지 파괴 · 대규모 아사 · 2년 연속 겨울 후 인구 5명 미만

## 주요 시스템

| 시스템 | 내용 |
|---|---|
| 지도 | 44×44 절차 생성 타일맵 (숲/평지/강/산지/비옥지/바위·철광). 숲 덩어리엔 난이도별 확률로 짐승 서식지가 생긴다. 겨울엔 눈과 얼어붙은 강으로 표현 |
| 주민 에이전트 | 생산은 전역 수치 계산이 아니라 **개별 주민의 이동·작업·운반**으로 이뤄진다. 하루는 8서브틱으로 나뉘고, 주민은 BFS 경로탐색으로 작업지까지 걸어가 일한 뒤 짐을 지고 창고/거점에 부려야 자원이 계상된다. 겨울엔 이동이 느려지고, 언 강 위로는 걸어 건널 수 있으며(해빙기 제외), 눈보라엔 실외 작업자가 대피한다. 벌목한 숲은 개활지가 되고 봄여름에 천천히 재생한다 |
| 자원 | 식량·장작·목재·돌·철·도구·가죽·옷·약초·곡물·사냥감·명성·방어도 |
| 주민 | 개별 객체: 이름·나이·직업·배고픔·체온·건강·사기·숙련도·위치·지게 짐. 매일 식량 소비, 겨울 체온 하락, 건강 0이면 사망 |
| 직업 | 무직/벌목꾼/사냥꾼/농부/건축가/운반꾼/약초꾼/대장장이/파수꾼/수비병. 운반꾼은 창고에서 장작 패기·사냥감 손질·도정을 하고 남는 손으로 채석하며, 대장장이는 철이 떨어지면 철광까지 채굴을 다녀온다. 파수꾼은 방어 시설 사이를 순찰한다 |
| 건물 | 15종: 중심지·초가집·온돌집·창고·벌목장·사냥막·약초막·밭·대장간·가죽공방·봉수대·목책·망루·군영·장터. 창고/벌목장/사냥막/약초막은 **하역 거점**이라 작업지 가까이 지을수록 운반 거리가 줄어 실질 효율이 오른다 (건물 배치가 곧 밸런스) |
| 계절/날씨 | 봄/여름/가을/겨울 + 맑음/비/서리/폭설/눈보라/혹한/해빙기 홍수. 눈보라·혹한은 장작 소모와 체온 손실 급증 |
| 생산 체인 | 숲→목재→장작, 철+목재→도구, 사냥감→식량+가죽, 가죽→옷, 밭→곡물→식량, 약초→치료 보조 |
| 습격 | 위협도(비축량·방어도·계절·명성·교역 거절에 반응)가 차면 **습격 무리가 지도 북쪽 가장자리에 실제로 나타나 마을로 접근**한다. 봉수대/망루가 있으면 스폰 즉시 경보가 울리고 무리가 천천히 오지만(대비 시간), 기습이면 빠르게 들이닥치고 경계 거리 안에 와서야 발견된다. 무리는 산과 **완공된 성벽 계열(목책·토성·석벽·성문)**을 못 지나며 강은 여울로 건넌다. 목책에 틈이 있으면 돌아 들어오고, 마을이 완전히 둘러싸여 있으면 **목책 앞에서 멈춰 공성**한다(방어 판정 +15%). 마을에 닿으면 6가지 대응 선택지(피난/수비병 요격/민병 징집/공물/협상/봉수 경보)가 열리고, 결과는 약탈/부상/건물 파손 중심. 수비병 요격은 훈련된 소수, 민병 징집은 성한 주민 전체가 싸운다(방어도 상승·부상 확산) |
| 북방 세력 | 조선 기록의 두만강 방면 여진 분류(오도리·올량합·올적합/우디캐)에서 딴 6개 세력. **습격 성향과 교역 품목이 세력마다 분리**되어 있다 — 오도리 씨족(정착 농경, 곡물·가죽 교역), 올량합 부락(반농반렵, 국경 무역), 골간 우디캐(하구 어로, 마른 생선), 니마차 우디캐(수렵, 평시엔 담비 가죽 상인·흉년엔 습격), 홀라온 야인(원거리 기마 습격), 변경 마적(조선 유민·여진 낙오자 혼성 도적). 위협도가 극에 달하면 평화 성향 씨족도 굶주림에 몰려 내려올 수 있다 |
| 세력 우호도 | 세력마다 0~100 관계 수치가 있고 인스펙터 "세력" 탭에서 볼 수 있다. **교역 수락/공물/협상 성공은 관계를 데우고, 거절/전투/봉수 경보는 식힌다.** 관계가 나쁜 세력일수록 습격에 나설 확률이 높고, 적대 세력들과의 평균 관계가 나쁘면 위협도가 빨리 오른다. 장터 협상 성공률은 조정 명성(60%)과 그 세력과의 관계(40%)로 정해지고, 습격 문구에도 관계가 반영된다("낯익은 얼굴들…"/"해묵은 원한…"). 관계는 시간이 지나면 각 세력의 기본 성향으로 서서히 되돌아간다 |
| 경제 보정 | 도구 부족 시 생산 효율 하락, 옷 부족 시 겨울 체온 손실 증가, 장작 부족 시 온돌 보너스 소멸 |

## 코드 구조

```
src/
  game/          # 순수 시뮬레이션 로직 (React 무관)
    config.ts    # 모든 밸런스 수치 (여기만 고치면 튜닝 가능)
    constants.ts # 명칭/텍스트/세력 정의
    types.ts     # 타입 정의
    simulation.ts# 오케스트레이터 (advanceTick: 서브틱 진행 + 일일 처리)
    agents.ts    # 주민 에이전트: BFS 경로탐색, 직업별 이동/작업/운반 행동
    map.ts       # 절차적 지도 생성 + 시드 난수
    residents.ts # 주민 생존 판정
    buildings.ts # 건물 정의/방어도 계산
    raids.ts     # 위협도/습격 이벤트
    relations.ts # 세력별 우호도
    events.ts    # 로그/교역/잡보
    weather.ts / seasons.ts / resources.ts / saveLoad.ts
  render/        # 렌더링 계층
    sprites.ts   # SpriteAPI 인터페이스 + 임시 그래픽(도형/이모지) 구현
    atlas.ts     # Kenney 스프라이트시트 구현 (기본 사용, CC0)
    renderer.ts  # 장면 렌더러: 지형 레이어 캐싱, 엔티티/오버레이, 히트 판정
  components/    # UI (TopBar, GameCanvas, BuildMenu, JobPanel,
                 #     InspectorPanel, EventLog, AlertsPanel, TimeControls, EventModal)
```

## 사운드

외부 오디오 파일 없이 **Web Audio API 절차 합성**([sfx.ts](src/sound/sfx.ts))으로 소리를 만듭니다.
습격 경보(뿔나팔+북), 교역(방울), 완공/회복(차임), 사망(조종풍 저음), 자원 부족 경고, 건설 착수(망치질),
승리/패배 멜로디가 있고, 눈보라·혹한·폭설 동안에는 바람 앰비언트 루프가 세기별로 깔립니다.
효과음은 이벤트 로그의 종류(kind)에 자동 연동되므로 게임 로직에 사운드 코드가 섞이지 않습니다.
상단 바의 🔊 버튼으로 켜고 끌 수 있으며 설정은 저장됩니다.

## 그래픽 구조 (교체/확장 가이드)

렌더링은 게임 로직과 분리된 `src/render/` 계층을 거치며, 현재 **Kenney CC0 스프라이트가 기본**입니다.

- **교체 지점은 `sprites.ts`의 `SpriteAPI` 하나뿐입니다.** `atlas.ts`가 그 구현 예시입니다 —
  다른 타일셋으로 바꾸려면 같은 인터페이스를 구현한 객체를 만들어 `renderScene`에 넘기면 됩니다.
  이미지 로드 전에는 `placeholderSprites`(도형/이모지)로 자동 폴백합니다.
- `atlas.ts` 상단의 좌표 상수(`GRASS`, `TREES_GREEN`, `BUILDING_SPRITES` 등)만 고치면
  타일 배정을 바꿀 수 있습니다. 시트 규격: 16×16 타일, 1px 간격(pitch 17).
- 계절 표현: 나무는 계절별 스프라이트 풀(초록/단풍/침엽수)에서 타일 좌표 해시로 결정적으로 고르고,
  가을엔 갈색 워시, 겨울엔 크림색 지면 + 눈 워시 + 언 강 균열을 덧그립니다.
- 강가: 물 타일의 뭍 방향에 못(pond) 가장자리 타일에서 잘라 낸 흙둑 띠를 붙여 물가를 표현합니다
  (겨울엔 얼음 표현으로 대체). 주민/습격자는 이동 중 1px 보브 + 방향 반전으로 걷는 연출이 붙고,
  건설 메뉴 아이콘도 같은 스프라이트로 그린 썸네일입니다.
- 날씨 오버레이(renderer의 `drawWeather`): 비/해빙 홍수는 사선 빗줄기 + 푸른 색조, 폭설·눈보라는
  흩날리는 눈송이 + 흰 안개(눈보라는 옆으로 몰아침), 서리는 반짝이는 결정, 혹한은 강한 푸른 색조 +
  가장자리 비네트로 표현합니다. 상태 없이 시간·인덱스로 위치를 계산하는 절차적 파티클이라
  게임 루프의 매 프레임 리렌더로 자연히 애니메이션됩니다.
- 밤낮 사이클(renderer의 `drawDayNight`): 하루 진행도(`subTick` + 이동 보간 계수)로 새벽→한낮→
  해질녘→한밤중을 계산해 색조를 입힙니다. 낮은 무색, 여명·황혼은 따뜻한 빛(새벽은 노랗게·해질녘은
  붉게), 밤은 푸른 어둠이 깔리고 집·온돌집·군영·중심지 창에 노란 불이 켜집니다. 밤낮을 느긋하게
  볼 수 있도록 `config.time.msPerDay`의 1배속을 8초/일로 늦췄습니다(3배 2.7초, 10배 0.8초).
- 건물은 몸체 타일 + 위 타일에 걸치는 지붕 + 구분용 소형 표식(모루=대장간, 모닥불=온돌/봉수대 등)의
  조합이며, 지붕 겹침 때문에 y 순서로 그립니다.
- **레이어 구조**: 지형은 오프스크린 캔버스에 캐싱되어 날짜/날씨/건물 변화 때만 다시 그려지고,
  유닛/오버레이만 매 프레임 그립니다. 이동은 서브틱 사이 보간이 적용되어 있어
  걷기 애니메이션 프레임만 얹으면 됩니다.
- 타일 크기는 `config.ts`의 `ui.tileSize` 하나로 제어됩니다.

에셋 출처: Kenney (kenney.nl) — Roguelike/RPG Pack, Roguelike Characters. CC0(퍼블릭 도메인)이라
표기 의무는 없지만 감사의 뜻으로 명기합니다.

브라우저 콘솔에서 `__game.run(30)` 으로 30일 빨리감기, `__game.state()` 로 상태 확인이 가능합니다(개발용).

## 남은 한계

- 습격 무리는 지도 위로 접근해 목책 앞에서 공성까지 하지만, 전투 자체는 확률 판정 1회로 해소됩니다(개별 전투원 교전 없음).
- 가죽공방은 작업자 없이 자동 가동되고, 식사/취침 등 일과는 일 단위로 추상화되어 있습니다(주민이 집에 드나드는 연출 없음).
- 습격 도중에 목책을 지으면 이미 계산된 접근 경로에는 반영되지 않습니다(다음 습격부터 적용).
- 밸런스는 봇 시뮬레이션(방치/적극 운영 시나리오)으로 조정했으나 실제 플레이 피드백이 더 필요합니다.
